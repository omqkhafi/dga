## Decisions worth knowing

- **Second Nav date and time** use Figma's Western digits (`3-سبتمبر-2024`, `2:30 مساءً`) as the finding quotes them. The whole strip stays in one digit system, and `scripts/locale-purity.test.ts` has a narrow exemption for these three forms.
- **Chart** is a DGA component, not an extension. Series 5 and 6, the Brand style and axis titles are not built (Deviation).
- **Tabs More menu** is opt-in (`TabsList overflow="menu"`); scrolling stays the default.
- **Footer accordion** is the optional `collapsible` prop and is off by default.
