كود المنصات سجل shadcn، فيعمل خادم shadcn MCP الرسمي معه كما هو. لا يوجد خادم مخصص: يسأل المساعد خادم shadcn، ويقرأ الخادم `@dga`.

## سجّل السجل

أضف `@dga` إلى `components.json`. الأمر `npx shadcn@latest init https://dga.omqkhafi.dev/r/dga.json` يفعل هذا أصلًا.

```json title="components.json"
{
  "registries": {
    "@dga": "https://dga.omqkhafi.dev/r/{name}.json"
  }
}
```

## هيّئ الخادم

يكتب سطر الأوامر الإعداد لعميلك.

## الإعداد اليدوي

أو أضف الخادم إلى الملف الذي يقرأه عميلك. الأمر هو `npx` ووسيطاه `shadcn@latest` و`mcp`.

<Tabs items={["Claude Code", "Cursor", "VS Code"]}>
<Tab value="Claude Code">

```json title=".mcp.json"
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    }
  }
}
```

</Tab>
<Tab value="Cursor">

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",

    }
  }
}
```

</Tab>
<Tab value="VS Code">

```json title=".vscode/mcp.json"

    "shadcn": {
```

</Tab>
