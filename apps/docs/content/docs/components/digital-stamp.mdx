## Usage

```tsx title="layout.tsx"
import { DigitalStamp } from "@/components/dga/digital-stamp";
import { Header } from "@/components/dga/header";

export function SiteHeader() {
  return <Header stamp={<DigitalStamp domain="gov.sa" />} logo={<Logo />} items={items} />;
}
```

Put the stamp at the very top of every page of a government site, above the [Second Nav](/docs/components/second-nav) and the [Header](/docs/components/header): pass it in the Header's `stamp` slot, which sits above `top`. It tells visitors the site is official and lets them check it: the address ends in a Saudi domain, the connection is HTTPS, and the site is registered with the Digital Government Authority. The banner reads "A government website registered with the Digital Government Authority." with the button "How you know?". Each `domain` has its own text; set it to the suffix your site uses and pass `registrationNumber` for the link in the registration card. Every string is a prop with an English default; translate them on Arabic pages.

In Arabic the flag and text start on the right and the toggle follows the text; the items and the card run from the right. The domain suffix and the registration number stay left to right and isolated from the Arabic around them.

## Anatomy

- **Banner**: 32px high, `background-neutral-100`, Text sm Medium, padded with `section-padding`. On mobile the text and the button stack vertically.
- **Saudi flag** (optional): `hideIcon` removes it.
- **Toggle**: a real button with `aria-expanded` and `aria-controls` that opens the panel.
- **Panel**: two items with a circular icon outlined in `icon-success` and a Text lg Semibold heading, then the registration card; on mobile they stack vertically. The first item is the DGA Extension part: its heading ends with the domain suffix in green (`gov.sa`, `edu.sa`, `med.sa`, `org.sa`, `sch.sa` or `.sa`), and each suffix has its own text. The second explains HTTPS.
- **Registration card**: the DGA logo, "Registered on Digital Government Authority:" and the registration number as a link (`registrationNumber`, `registrationHref`). Pass `registrationLabel={null}` to leave the card out.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the toggle. |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Opens or closes the panel. |
| <kbd>Esc</kbd> | Closes the panel and keeps focus on the toggle. |

- The banner is a labelled region. The toggle reports `aria-expanded` and points to the panel with `aria-controls`; a closed panel is hidden from the accessibility tree.
- The panel opens without animation, so reduced-motion settings need no special case. The chevron's turn is switched off with reduced motion.
- Text is 4.5:1 on the banner, the toggle, the green domain suffix and the registration link too, with a 2px focus ring, in light and dark.

## Deviations from DGA

- The wording and layout follow the DGA Digital Stamp. The flag and the DGA mark are redrawn as inline SVG because the official artwork is not in the registry; replace the logo with `registrationLogo`.
- On mobile the banner and panel stack vertically in one component instead of using a separate mobile frame.
- The Extension part is a row in the panel, not a separate 88px bar.
