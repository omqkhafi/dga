## Usage

```tsx title="layout.tsx"
import { DigitalStamp } from "@/components/dga/digital-stamp";
import { Header } from "@/components/dga/header";

export function SiteHeader() {
  return <Header stamp={<DigitalStamp domain="gov.sa" />} logo={<Logo />} items={items} />;
}
```

Put the stamp at the very top of every page of a government site, above the [Second Nav](/docs/components/second-nav) and the [Header](/docs/components/header): pass it in the Header's `stamp` slot, which sits above `top`. It tells visitors the site is official and lets them check it: the address ends in a Saudi domain, the connection is https, and the site is registered with the Digital Government Authority. DGA gives the layout but no wording, so every string is a prop with an English default; translate them on Arabic pages. Set `domain` to the suffix your site uses.

## Anatomy

- **Strip**: 32px high, `background-neutral-100`, Text sm Medium, padded with `section-padding`. On narrow screens it wraps to a second line.
- **Flag icon** (optional): `hideIcon` removes it.
- **Toggle**: a real button with `aria-expanded` and `aria-controls` that opens the panel.
- **Panel**: one row per check, with an `icon-success` icon and a Text lg Semibold heading. The first row is the DGA Extension part: it shows the domain suffix (`gov.sa`, `edu.sa`, `med.sa`, `org.sa`, `sch.sa` or `.sa`). Pass `registrationTitle={null}` to leave the registration row out.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the toggle. |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Opens or closes the panel. |
| <kbd>Esc</kbd> | Closes the panel and keeps focus on the toggle. |

- The strip is a labelled region. The toggle reports `aria-expanded` and points to the panel with `aria-controls`; a closed panel is hidden from the accessibility tree.
- The panel opens without animation, so reduced-motion settings need no special case. The chevron's turn is switched off with reduced motion.
- Text is 4.5:1 on the strip and the toggle too, with a 2px focus ring, in light and dark.

## Deviations from DGA

- DGA's Figma has the strip (closed and opened, desktop and mobile) and the Extension part, but no wording or artwork. The wording, the flag icon and the rows for https and registration are new, no DGA source.
- The strip wraps on narrow screens instead of using a separate mobile frame.
- The Extension part is a row in the panel, not a separate 88px bar.
