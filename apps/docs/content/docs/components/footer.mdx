## Usage

```tsx title="layout.tsx"
import { YoutubeIcon, ZoomInAreaIcon } from "@hugeicons/core-free-icons";
import { Footer } from "@/components/dga/footer";

export function SiteFooter() {
  return (
    <Footer
      logo={<img src="/logo.svg" alt="Digital Services" height={40} />}
      partnerLogos={<img src="/platforms.svg" alt="National platforms" height={32} />}
      columns={[
        {
          title: "Services",
          links: [
            { label: "Renew a licence", href: "/renew" },
            { label: "Pay a fee", href: "/pay" },
          ],
        },
        { title: "Support", links: [{ label: "Help centre", href: "/help" }] },
      ]}
      socialTitle="Social media"
      social={[{ label: "YouTube", href: "https://youtube.com", icon: YoutubeIcon }]}
      accessibilityTitle="Accessibility tools"
      accessibilityTools={[{ label: "Zoom in", icon: ZoomInAreaIcon, onClick: () => {} }]}
      bottomLinks={[{ label: "Sitemap", href: "/sitemap" }]}
      legalLinks={[
        { label: "Terms and conditions", href: "/terms" },
        { label: "Privacy policy", href: "/privacy" },
      ]}
      copyright="© 2026 Digital Services. All rights reserved."
    />
  );
}
```

Every text is a prop, so translate the titles and `columnsLabel`, `socialLabel`, `bottomLabel`, `legalLabel` and `externalLabel` on Arabic pages. Everything follows the direction: the brand block sits at the start edge and the groups run from it.

## Anatomy

- **Footer**: gray (neutral-100) or `tone="green"` (the DGA flag green with on-colour text). Padded 32px, content centred and 1280px wide unless `fullWidth`.
- **Logos**: `logo`, and `partnerLogos` for the platform logos, which always sit on a white tile so they read on both tones.
- **Link groups** (`columns`): a heading with a divider under it and a list of links; up to four across, two across below `sm`.
- **Social Media** (`social`, `socialTitle`): a titled block of bordered icon links.
- **Accessibility Tools** (`accessibilityTools`, `accessibilityTitle`): a titled block of bordered icon buttons, for example zoom and contrast. A tool is a button, a link with `href`, or a toggle with `pressed`.
- **Bottom links** (`bottomLinks`): a row of underlined links.
- **Legal row** (`copyright`, `legalLinks`): the copyright, the terms and the privacy policy, under a line. Centred below `sm`.
- **Optional**: `description`, `contact` and `badges` (app store badges) are not DGA parts and are off by default.
- **Small screens**: the groups stay open in two columns. `collapsible` folds them into an Accordion, one section per group.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves through the links in reading order. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Presses a tool button, or opens or closes an Accordion section when `collapsible` is on. |

- A `footer` landmark. The link columns are a `nav` named by `columnsLabel`, the bottom links are a `nav` named by `bottomLabel`, and the legal links are another named by `legalLabel`. Each tool has an accessible name from its `label`. Contact details are a list; the kind of detail is read by screen readers.
- External links open in a new tab, show an icon and have a screen-reader note (`externalLabel`).
- Focus is a 2px outline: black on gray and white on green. Text is 4.5:1 and icons 3:1 in light and dark.

## Deviations from DGA

- The 72px heading and its 24px paragraph of the DGA CSS are not shipped: the footer has a description in Text md, and you place any hero text yourself.
- Colours are the semantic tokens, not hard-coded values, so the dark theme works.
- Figma changes only the weight below 600px. Here the groups go to two columns and the legal row is centred; the Accordion is an option (`collapsible`).
- The description, contact details and app badges are added and optional.
