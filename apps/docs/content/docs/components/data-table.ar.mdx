## الاستخدام [#usage]

```tsx title="page.tsx"
import type { ColumnDef } from "@tanstack/react-table";
import { DataTable } from "@/components/dga/data-table";

type Request = { id: string; service: string };

const columns: ColumnDef<Request>[] = [
  { accessorKey: "id", header: "الطلب" },
  { accessorKey: "service", header: "الخدمة" },
];

export function Requests({ rows }: { rows: Request[] }) {
  return (
    <DataTable aria-label="الطلبات" columns={columns} data={rows} pageSize={10} selectable />
  );
}
```

استخدمه لسجلات يحتاج الناس إلى ترتيبها أو البحث فيها أو اختيار منها. والجدول يعمل على جهة العميل: يرتّب `data` التي تعطيها ويصفّيها ويقسمها صفحات. وللبيانات الكبيرة جدًا أو المرقّمة من الخادم استخدم [Table](/docs/components/table) و[Pagination](/docs/components/pagination) بحالتك أنت. والأعمدة تعريفات أعمدة TanStack Table: أعطِ كل عمود `header` نصًا (أو `meta: { label }`) ليُسمّى زر الترتيب.

تمتد الأعمدة من اليمين، وتنعكس أسهم الترقيم.

## البنية [#anatomy]

- **الجدول**: Table من DGA بصفوف متبادلة، في منطقة تتمرر أفقيًا.
- **الترتيب**: زر ترتيب في كل عنوان قابل للترتيب؛ ويحمل العنوان `aria-sort`.
- **التحديد**: عمود خانات اختيار؛ وتحدد خانة الرأس الصفحة وتُظهر شرطة حين يُحدَّد بعض الصفوف.
- **التذييل**: النطاق («من 1 إلى 5 من 12») وعدد المحدد وPagination.
- **الحالات**: صفوف نائبة عند `loading`، ورسالة فراغ حين لا يطابق شيء.

### الترتيب والتصفية والتحديد والصفحات [#sorting-filtering-selection-and-pages]

اكتب في مربع البحث لتصفية كل الأعمدة، واختر زر العنوان للترتيب، واستخدم خانات الاختيار للتحديد. مرّر `globalFilter` من حقلك أنت؛ ويتلقى `onSelectionChange` الصفوف المحددة.

يعرض `loading` صفوفًا نائبة ويعلن «جارٍ التحميل». ومن دون صفوف يعرض الجدول `emptyState` أو رسالة `labels.empty`. ويعرض `pageSize={0}` كل الصفوف دون ترقيم.

### التسميات [#labels]

كل نص يعرضه الجدول بنفسه موجود في `labels`: ترجمها، ومرّر `formatNumber` داخل `labels.pagination` للأرقام الهندية.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينتقل عبر أزرار الترتيب وخانات الاختيار ومحتوى الخلايا والترقيم. |
| <kbd>Enter</kbd> | يضغط زر ترتيب أو صفحة. |
| <kbd>Space</kbd> | يبدّل خانة اختيار مركَّزة. |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowRight</kbd> | يمرّر جدولًا عريضًا مركَّزًا أفقيًا. |

- جدول دلالي: ترتيب الفرز في `aria-sort`، وللصفوف المحددة `aria-selected`، وكل خانة اختيار مسمّاة («تحديد الصف 3»).
- سطر النطاق منطقة حية مهذبة، فيُعلَن الترقيم والتصفية. وأثناء التحميل يكون الجدول `aria-busy` وتخبر حالة بذلك.
- لمنطقة التمرير اسم وتقبل التركيز، فيصل مستخدم لوحة المفاتيح إلى الأعمدة التي لا تتسع.
