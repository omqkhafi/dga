## الاستخدام [#usage]

```tsx title="page.tsx"
import { Button } from "@/components/dga/button";
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@/components/dga/empty";

export function NoRequests() {
  return (
    <Empty>
      <EmptyHeader>
        <EmptyMedia variant="icon">{/* أيقونة */}</EmptyMedia>
        <EmptyTitle>لا توجد طلبات بعد</EmptyTitle>
        <EmptyDescription>تظهر هنا الطلبات التي تقدمها.</EmptyDescription>
      </EmptyHeader>
      <EmptyContent>
        <Button>طلب جديد</Button>
      </EmptyContent>
    </Empty>
  );
}
```

استخدم Empty حين لا يوجد ما يُعرض في منطقة كاملة: لا نتائج، أو لم يُنشأ شيء بعد، أو مجلد بلا ملفات، أو خطأ ترك المنطقة فارغة. اذكر السبب والخطوة التالية. يحتفظ [Data Table](/docs/components/data-table) بصفه الفارغ المدمج للجدول؛ واستخدم Empty للصفحة أو البطاقة المحيطة به.

## البنية [#anatomy]

- **الوسائط**: الأيقونة بلون `icon-default-500`، أو مع `variant="icon"` على تعبئة دائرية بقطر 48px بلون `background-neutral-100` ورمز `icon-default`.
- **العنوان**: `text-lg` شبه عريض بلون `text-display`. وهو فقرة لا عنوان، فيناسب أي مستوى عناوين في الصفحة.
- **الوصف**: `text-md` بلون `text-primary-paragraph`. والرابط داخله بلون الرابط في DGA.
- **المحتوى**: أزرار أو حقل، موسّطة تحته.
- **الحد** (اختياري): يرسم `bordered` خطًّا متقطعًا بلون `border-neutral-primary`، لمنطقة فارغة داخل صفحة.

## إمكانية الوصول [#accessibility]

- Empty محتوى عادي بلا دور. إن حلّ محل نتائج كانت تُحمَّل فأعلن التغيير بمنطقة حية في صفحتك، مثل [Inline Alert](/docs/components/inline-alert) بالدور `role="status"`.
- أخفِ الأيقونات الزخرفية عن قارئات الشاشة (`aria-hidden`).
- النص 4.5:1 والأيقونات 3:1 أو أفضل على كل سطح، فاتحًا وداكنًا.

## الاشتقاق من DGA [#derivation-from-dga]

لا تعرّف DGA حالة فارغة مستقلة؛ ففي Data Table صف فارغ واحد. يحتفظ هذا المكوّن بأيقونة ذلك الصف وألوان نصه وتوسيطه، ويضيف التخطيط والحد المتقطع وتعبئة الأيقونة الدائرية. ولا لون جديد فيه.
