## الاستخدام [#usage]

```tsx title="page.tsx"
import { useState } from "react";
import { Rating } from "@/components/dga/rating";

export function RateService() {
  const [value, setValue] = useState(0);
  return <Rating aria-label="قيّم هذه الخدمة" value={value} onValueChange={setValue} />;
}
```

استخدم التقييم لسؤال الناس عن رضاهم ولعرض النتيجة. واقرنه بطريقة لقول السبب حين تكون الدرجة منخفضة. واستخدم `readOnly` لعرض درجة (متوسط أو إجابة مرسلة). ويعرّف DGA نجومًا كاملة، فلا نجوم نصفية.

## البنية [#anatomy]

- **النجوم**: خمس، بحجم 24 أو 32 أو 48px، بينها 4px (قيمة `size` هي `sm` أو `md` أو `lg`).
- **اللون**: `background-secondary` (ذهبي) أو `background-primary` مع `brand`. وكل نجمة بحد خارجي ليتضح شكلها.
- **التفاعلي**: مجموعة أزرار اختيار. والمرور على نجمة يعاين التقييم.
- **للقراءة فقط**: صورة ببديل نصي، «التقييم 4 من 5».

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | يدخل التقييم (إلى النجمة المختارة أو الأولى) ثم يخرج منه. |
| <kbd>ArrowRight</kbd> | يختار النجمة التالية (والسابقة بالعربية). |
| <kbd>ArrowLeft</kbd> | يختار النجمة السابقة (والتالية بالعربية). |
| <kbd>Space</kbd> | يختار النجمة المركَّزة. |

- مبنية على Base UI Radio Group: `radiogroup` من أزرار اختيار مسمّاة «نجمة واحدة» و«نجمتان» وهكذا، وأحدها في ترتيب Tab.
- التقييم للقراءة فقط `img` مسمّى بـ `summaryLabel`، فلا تكون الدرجة في النجوم وحدها.
- حد النجمة 3:1 على الصفحة فاتحًا وداكنًا، فيتضح الشكل رغم أن التعبئة الذهبية وحدها 2.30:1.
