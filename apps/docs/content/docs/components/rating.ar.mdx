## الاستخدام [#usage]

```tsx title="page.tsx"
import { useState } from "react";
import { Rating } from "@/components/dga/rating";

export function RateService() {
  const [value, setValue] = useState(0);
  return <Rating aria-label="قيّم هذه الخدمة" value={value} onValueChange={setValue} />;
}
```

استخدم التقييم لسؤال الناس عن رضاهم ولعرض النتيجة. واقرنه بطريقة لقول السبب حين تكون الدرجة منخفضة. واستخدم `readOnly` لعرض درجة (متوسط أو إجابة مرسلة). وأضف `allowHalf` حين تحتاج الدرجة إلى أنصاف النجوم؛ والتقييم للقراءة فقط يرسم أيضًا قيمة كسرية مثل 4.3.

النجمة الأولى عند جهة البداية: في العربية على اليمين، وتنمو التعبئة من اليمين (وتمتلئ النجمة النصفية من نصفها الأيمن) ويرفع السهم الأيسر التقييم.

## البنية [#anatomy]

- **النجوم**: خمس، بحجم 24 أو 32 أو 48px، بينها 4px (قيمة `size` هي `sm` أو `md` أو `lg`).
- **اللون**: `background-secondary` (ذهبي) أو `background-primary` مع `brand`. وكل نجمة بحد خارجي ليتضح شكلها.
- **نصف نجمة**: مع `allowHalf` يكون لكل نجمة نصف في جهة البداية ونصف في جهة النهاية، ويمتلئ نصف البداية أولًا.
- **الحالات**: المرور يعاين التقييم، والضغط يصغّر النجمة قليلًا، وللنجمة المختارة حد أسمك؛ ويظهر إطار عند التركيز.
- **التفاعلي**: مجموعة أزرار اختيار (زرّان لكل نجمة مع `allowHalf`).
- **للقراءة فقط**: صورة ببديل نصي، «التقييم 4 من 5».

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | يدخل التقييم (إلى النجمة المختارة أو الأولى) ثم يخرج منه. |
| <kbd>ArrowRight</kbd> | يختار النجمة التالية (والسابقة بالعربية). |
| <kbd>ArrowLeft</kbd> | يختار النجمة السابقة (والتالية بالعربية). |
| <kbd>Space</kbd> | يختار النجمة المركَّزة. |

مع `allowHalf` يتحرك كل مفتاح سهم بمقدار نصف نجمة.

- مبنية على Base UI Radio Group: `radiogroup` من أزرار اختيار مسمّاة «نجمة واحدة» و«نجمتان» وهكذا («نجمتان ونصف» مع `allowHalf`)، وأحدها في ترتيب Tab.
- التقييم للقراءة فقط `img` مسمّى بـ `summaryLabel`، فلا تكون الدرجة في النجوم وحدها.
- حد النجمة 3:1 على الصفحة فاتحًا وداكنًا، فيتضح الشكل رغم أن التعبئة الذهبية وحدها 2.30:1.

## الاختلافات عن DGA [#deviations-from-dga]

- يلوّن CSS النجوم بـ `#faaf00` ويستخدم Figma `background-secondary` (2.30:1). وتُحاط النجوم بحد لتبلغ 3:1.
- تعرّف DGA نجومًا نصفية وحالتي الضغط والاختيار، وهي مبنية هنا. ومظهر الضغط (تصغير إلى 90%) ومظهر الاختيار (حد 2px بدل 1.5px) من تقديرنا لهما. وأُضيف التركيز بلوحة المفاتيح والمرور.
