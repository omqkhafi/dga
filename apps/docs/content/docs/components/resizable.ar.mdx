## الاستخدام [#usage]

```tsx title="page.tsx"
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@/components/dga/resizable";

export function Requests() {
  return (
    <ResizablePanelGroup className="h-56 rounded-md border">
      <ResizablePanel id="list" defaultSize="35%" minSize="20%">
        الطلبات
      </ResizablePanel>
      <ResizableHandle withHandle aria-label="تغيير حجم لوحة الطلبات" />
      <ResizablePanel id="detail" defaultSize="65%">
        تفاصيل الطلب
      </ResizablePanel>
    </ResizablePanelGroup>
  );
}
```

استخدمها لمساحة عمل يقرر الناس فيها حجم كل جزء: قائمة بجانب تفاصيلها أو محرر فوق وحدة تحكم. ولتخطيط ثابت استخدم شبكة عادية. الأحجام نسب مئوية (`"35%"`) أو بكسل (`240`). تملأ المجموعة أصلها، فأعطِ الأصل ارتفاعًا.

اللوحة الأولى هي لوحة البداية: على اليسار في الإنجليزية وعلى اليمين في العربية. ولأن المكتبة تعمل من اليسار إلى اليمين فقط، تُرتَّب المجموعة في العربية من اليسار إلى اليمين مع عكس ترتيب اللوحات، فيفعل السحب ومفاتيح الأسهم ما تتوقعه العين: يحرّك <kbd>←</kbd> المقبض إلى اليسار في اللغتين. ويُعكس سلوك Home وEnd وEnter تلقائيًا فتعمل على لوحة البداية في اللغتين. وتحتفظ كل لوحة باتجاهها، فيُقرأ محتواها من اليمين إلى اليسار.

## البنية [#anatomy]

- **المجموعة**: ترتّب اللوحات في صف (`orientation="horizontal"` وهو الافتراضي) أو في عمود.
- **اللوحة**: تحمل المحتوى. حدّد `defaultSize` و`minSize` و`maxSize`. واللوحة `collapsible` تنطوي إلى `collapsedSize` حين تُسحب إلى ما دون `minSize`.
- **المقبض**: خط بسمك 1px بلون `text-secondary-paragraph` ومساحة لمس أوسع غير مرئية. عند المرور والسحب والتركيز يصير `icon-default`، ويضيف التركيز حلقة بسمك 2px بلون `border-black`.
- **مقبض الإمساك** (اختياري): `withHandle` يضيف مقبضًا صغيرًا بأيقونة `icon-default` ليسهل العثور على المقبض.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | يركّز على المقبض. |
| <kbd>←</kbd> <kbd>→</kbd> | يحرّكان مقبضًا عموديًا 5%. |
| <kbd>↑</kbd> <kbd>↓</kbd> | يحرّكان مقبضًا أفقيًا 5%. |
| <kbd>Home</kbd> <kbd>End</kbd> | يرسلان المقبض إلى بداية المجموعة أو نهايتها (اليمين أو اليسار في العربية). |
| <kbd>Enter</kbd> | يطوي اللوحة التي قبل المقبض أو يفتحها إن كانت قابلة للطي. |

- المقبض عنصر `separator` له `aria-orientation` و`aria-valuenow` و`aria-valuemin` و`aria-valuemax` و`aria-controls`، ويأخذ التركيز. مرّر `aria-label` لتسميته.
- الخط بنسبة 3:1 أو أفضل مقابل الصفحة، وحلقة التركيز بنسبة 3:1، في الوضعين الفاتح والداكن.
- يعمل المؤشر واللمس ولوحة المفاتيح. والمقبض المعطّل يُتخطى.
