A skeleton shows the shape of content while it loads, so the page does not jump when it arrives.

<Preview name="skeleton" title="Shapes and sizes" />

## Installation

<ComponentInstall name="skeleton" />

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton";

<div aria-busy="true" aria-live="polite">
  <Skeleton shape="circle" size={48} />
  <Skeleton shape="line" size="lg" />
</div>
```

## Props

<TypeTable
  type={{
    shape: { type: '"rectangle" | "square" | "circle" | "line"', default: '"rectangle"' },
    size: {
      type: '"sm" | "md" | "lg" | 24 | 48 | 64 | 80 | 120 | 170 | 240',
      description: "rectangle: sm 24, md 32, lg 40px high. line: sm 14, lg 22px. square and circle: the pixel size.",
    },
  }}
/>

Set widths with `className` (for example `w-32`).

## Accessibility

- Skeletons are hidden from screen readers. Set `aria-busy="true"` on the region that is loading, and remove it when the content arrives.
- The pulse stops with reduced motion.
