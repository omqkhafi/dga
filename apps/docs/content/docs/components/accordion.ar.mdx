## الاستخدام [#usage]

```tsx title="page.tsx"
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/dga/accordion";

export function ServiceFaq() {
  return (
    <Accordion defaultValue={["eligibility"]}>
      <AccordionItem value="eligibility">
        <AccordionTrigger>من يستطيع التقديم؟</AccordionTrigger>
        <AccordionContent>المواطنون والمقيمون ممن لديهم هوية سارية.</AccordionContent>
      </AccordionItem>
      <AccordionItem value="time">
        <AccordionTrigger>كم تستغرق المعالجة؟</AccordionTrigger>
        <AccordionContent>تُنجز معظم الطلبات خلال ٥ أيام عمل.</AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```

استخدم Accordion لمحتوى يتصفحه الناس بعناوينه ولا يفتحون منه إلا جزءًا: أسئلة وأجوبة أو أقسام نموذج طويل. ولا تخفِ ما يجب أن يقرأه الجميع. يُفتح قسم واحد في كل مرة افتراضيًا؛ وضبط `multiple` يتيح فتح عدة أقسام.

يقع السهم في جهة النهاية (اليسار بالعربية)، أو في جهة البداية مع `iconPosition="leading"`. وتُزاح نصوص اللوحة بحشوة منطقية لتحاذي نص العنوان. ولا حاجة إلى أي تجاوزات لـ `[dir=rtl]`. والجذر `Accordion` هو قائمة الأكورديون في DGA: يرصّ عناصره بعرض الحاوية كاملًا.

## البنية [#anatomy]

- **Accordion** (القائمة): الجذر. يضبط `size` و`variant` و`iconPosition` و`flush` و`multiple` لكل عناصره.
- **العنصر**: قسم واحد، وفوقه خط بسمك 1px. وتعرّفه `value`.
- **الزر** (`<button>` في عنوان): نص `md` بخط شبه عريض، وسهم يدور عند فتح القسم. الارتفاع وهو مغلق: 56px (`lg`) و48px (`md`) و40px (`sm`). الحالات: افتراضي، تحويم (عنوان رمادي)، ضغط، تركيز (حد 2px داخل العنوان)، وتعطيل.
- **اللوحة** (`role="region"`): المحتوى، بالحالات نفسها (نص رمادي عند التعطيل). وتحرّك ارتفاعها.

## أمثلة [#examples]

### الأحجام [#sizes]

يحدد `size` حشوة العنوان وارتفاعه مغلقًا: `lg` ‏56px (حشوة 16px) و`md` ‏48px (12px) و`sm` ‏40px (8px).

<Preview compact name="accordion-sizes" title="الأحجام" />

### أبيض ومعبأ [#white-and-filled]

`variant="white"` (الافتراضي) بلا تعبئة؛ و`variant="filled"` يعطي كل عنصر تعبئة `background-neutral-50`.

<Preview compact name="accordion-filled" title="أبيض ومعبأ" />

### بلا إطار [#flush]

يُبقي `flush` الخطوط على بعد 16px من الحافتين. وتحتفظ العناوين والمحتوى بعرضها الكامل ومحاذاتها.

<Preview compact name="accordion-flush" title="بلا إطار" />

### الأيقونة في البداية [#leading-icon]

يضع `iconPosition="leading"` السهم أولًا ويزيح المحتوى ليحاذي نص العنوان. وينعكس في العربية.

<Preview compact name="accordion-leading" title="الأيقونة في البداية" />

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينقل التركيز إلى العنوان التالي. |
| <kbd>Enter</kbd> | يفتح القسم المركَّز أو يغلقه. |
| <kbd>Space</kbd> | يفتح القسم المركَّز أو يغلقه. |

- مبنية على Base UI Accordion: كل عنوان `<button>` مع `aria-expanded` و`aria-controls` داخل عنصر عنوان؛ واللوحة `region` تسمّيها. واللوحة المغلقة مخفية عن قارئ الشاشة. وكما يطلب نمط WAI-ARIA يكفي Tab وEnter وSpace.
- تظهر حالة الفتح من دوران السهم ومن اللوحة نفسها لا من اللون. والتركيز حد بسمك 2px داخل العنوان.
- النص بنسبة 4.5:1 والسهم 3:1 أو أفضل في كل حالة، فاتحًا وداكنًا. ولا يمكن فتح القسم المعطّل.
- تفتح اللوحة وتغلق بتحريك ارتفاعها؛ ومع تقليل الحركة تفتح فورًا.

## الاختلافات عن DGA [#deviations-from-dga]

- يكرر CSS في DGA كل قاعدة حشوة للجسم لـ `[dir=rtl]` و`html[lang=ar]` (اثنتا عشرة قاعدة). أما الحشوة المنطقية (`ps` و`pe`) فلا تحتاج إلى أي منها.
- يُرسم الخط في `flush` بعنصر زائف على بعد 16px من كل حافة؛ بينما تستخدم DGA تدرج `border-image` عند 16px و382px، ولا يلائم إلا عرضًا واحدًا.
- النسخة المعبأة (`background-neutral-50`) ونص اللوحة الرمادي عند التعطيل من اختيارنا؛ ولا يُظهر CSS في DGA إلا العنصر الأبيض.
- يستخدم القسم المعطّل `text-default-disabled` بدل `neutral-300` مع `!important`.
