## Usage

```tsx title="page.tsx"
import { Badge } from "@/components/ui/badge";

<Badge variant="success">مقبول</Badge>
```

A badge is a short, non-interactive label. For labels the user can remove or select, use a [Tag](/docs/components/tag).

## Anatomy

- **Root**: a `<span>`.
- **Icon** (optional): before the text.
- **Label**: the text.

## Examples

### Sizes, shape and icons

`sm` is 20px, `md` 24px (default) and `lg` 32px high. `rounded` makes a pill, which suits counts. `iconOnly` makes a square (or circle) badge and needs an `aria-label`.

## Accessibility

- A `<span>` with no role. The text is read in place, so put the meaning in the text, not only in the colour (WCAG 1.4.1).
- For a count, add context: `<Badge>3<span className="sr-only"> unread</span></Badge>`.
- Icon-only badges need an `aria-label`, or `aria-hidden` if they are decorative.
