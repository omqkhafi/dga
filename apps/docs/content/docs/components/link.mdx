Links take the user to another page, or to a section on the same page. Use a [Button](/docs/components/button) for actions.

## Usage

```tsx title="app/page.tsx"
import NextLink from "next/link";
import { Link } from "@/components/ui/link";

<Link render={<NextLink href="/services" />}>الخدمات</Link>
```

Without `render`, `Link` renders a plain `<a>`.

## Inline

Inside running text, set `inline`. Inline links are always underlined, so they can be told apart without colour (WCAG 1.4.1).

<Preview name="link-inline" title="Inline" />

## External

`external` opens the link in a new tab with `rel="noopener noreferrer"`, adds the external-link icon (mirrored in RTL) and tells screen readers that it opens a new tab. Translate the hint with `externalLabel` on Arabic pages:

```tsx
<Link href="https://dga.gov.sa" external externalLabel="(يفتح في علامة تبويب جديدة)">
  هيئة الحكومة الرقمية
</Link>
```

## Accessibility

- A real `<a href>`, so it works with the keyboard, middle-click and "open in new tab".
- Visited links change colour (`link-primary-visited`). Hover and pressed also underline the link.
- The focus ring shows for keyboard focus only: 2px `border-black` with a 2px offset, white on brand fills.
- A disabled link has no `href`, cannot be focused and is announced as disabled.
