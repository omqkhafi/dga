Installs [Field](/docs/components/field) too. This is DGA's Dropdown Input; it is named Select after the Base UI part.

## Usage

```tsx title="page.tsx"
import { Field, FieldLabel } from "@/components/ui/field";
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";

const services = [
  { value: "issue", label: "Issue a licence" },
  { value: "renew", label: "Renew a licence" },
];

export function ServiceField() {
  return (
    <Field name="service">
      <FieldLabel required>Service</FieldLabel>
      <Select items={services} required>
        <SelectTrigger>
          <SelectValue placeholder="Choose a service" />
        </SelectTrigger>
        <SelectContent>
          {services.map((s) => (
            <SelectItem key={s.value} value={s.value}>
              {s.label}
            </SelectItem>
          ))}
        </SelectContent>
      </Select>
    </Field>
  );
}
```

Use Select to pick one option from five to fifteen. For fewer, [Radio](/docs/components/radio) shows every option at once; for many, add a search field. Pass `items` so the trigger shows the label of the chosen value, and a `placeholder` that says what to choose.

## Anatomy

- **Trigger** (`<button>`): the border, the chosen label or the placeholder, and a chevron.
- **Content**: the popup on the card surface, as wide as the trigger.
- **Item**: one option, with a check mark on the end side when chosen.
- **Group**, **Label** and **Separator** (optional): group related options.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the trigger. |
| <kbd>Enter</kbd>, <kbd>Space</kbd> or <kbd>ArrowDown</kbd> | Opens the list. |
| <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> | Moves between options. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Jumps to the first or last option. |
| Type a letter | Jumps to the option that starts with it. |
| <kbd>Enter</kbd> | Chooses the highlighted option and closes the list. |
| <kbd>Esc</kbd> | Closes the list and returns focus to the trigger. |

- The trigger has the `combobox` role with `aria-expanded`; the list has the `listbox` role and each option `option` with `aria-selected`.
- The label comes from [Field](/docs/components/field). Helper text and errors are linked with `aria-describedby`.
- The highlighted option has a 2px bar and a tint, not a tint alone (WCAG 2.4.7). The chosen option has a check mark.
- Every state keeps a 3:1 border and 4.5:1 text in light and dark.

## Deviations from DGA

- Named Select (Figma: Dropdown Input). Figma draws only the open list; the popup surface is ours.
- The highlighted option has a bar as well as a tint, because the tint alone is 1.1:1.
- Same states as [Input](/docs/components/input): no outline, a full underline when focused or open, and the press shows the half underline. A mouse press opens the list straight away, so it goes from rest to open.
