## الاستخدام [#usage]

```tsx title="page.tsx"
import { Carousel } from "@/components/dga/carousel";

export function Featured() {
  return (
    <Carousel aria-label="خدمات مميزة" controls="dots">
      <Slide title="جدّد ترخيصك إلكترونيًا" />
      <Slide title="تابع طلبك" />
      <Slide title="ادفع بأمان" />
    </Carousel>
  );
}
```

كل عنصر ابن شريحة. استخدم الشرائح المتحركة لعرض عدد قليل من العناصر المتكافئة في مساحة واحدة. ولا تخفِ بها محتوى يحتاج الناس إلى مقارنته أو قراءته. سمِّها بـ `aria-label` وترجم `previousLabel` و`nextLabel` و`pauseLabel` و`playLabel` و`slideLabel` و`dotLabel` و`dotsLabel` في الصفحات العربية.

## البنية [#anatomy]

- **الشرائح**: واحدة ظاهرة في كل مرة، يحركها المسار. في صفحة من اليمين إلى اليسار تكون الشريحة الأولى على اليمين ويتحرك المسار في الاتجاه المعاكس.
- **عناصر التحكم** (`controls`): `arrows` (السابق والتالي بجانب الشرائح)، أو `dots` (الأسهم والنقاط)، أو `dots-only`.
- **الأسهم**: 32 أو 40 أو 48px (`size`)، بنمط `primary` (تعبئة أساسية وأيقونة على اللون) أو `subtle` (`arrowStyle`). تُعطَّل عند الطرفين ما لم تستخدم `loop`.
- **النقاط**: 8 أو 12 أو 16px (`dotSize`) داخل هدف بحجم 24px. النقطة المختارة ممتلئة وغيرها حلقات.
- **زر الإيقاف المؤقت**: يظهر حين يكون `autoPlay` مفعّلًا.

### التشغيل التلقائي

## الاتجاه من اليمين إلى اليسار [#rtl]

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينتقل بين زر الإيقاف المؤقت والسابق والتالي والنقاط. تُتخطى الشرائح غير الظاهرة. |
| <kbd>Left</kbd> / <kbd>Right</kbd> | الشريحة السابقة أو التالية ما دام التركيز داخله. يتبادلان في الصفحات العربية. |
| <kbd>Home</kbd> / <kbd>End</kbd> | أول شريحة أو آخرها. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | يضغط الزر المركَّز. |

- عنصر `section` بـ `aria-roledescription="carousel"`. كل شريحة مجموعة اسمها «1 من 4» (`slideLabel`)؛ والشرائح غير الظاهرة `aria-hidden` و`inert`.
- يمكن إيقاف المحتوى المتحرك مؤقتًا (WCAG 2.2.2). أثناء التشغيل تكون المنطقة الحية مطفأة فلا يُقاطَع قارئ الشاشة؛ وفي غير ذلك تكون `polite`.
- على شاشات اللمس تنقل السحبة الأفقية شريحة واحدة، ويبقى التمرير الرأسي يعمل.
- الأسهم والنقاط 3:1، وكذلك حلقة التركيز، في الفاتح والداكن.
