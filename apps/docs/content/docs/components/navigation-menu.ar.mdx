## الاستخدام [#usage]

```tsx title="page.tsx"
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuLinkDescription,
  NavigationMenuLinkTitle,
  NavigationMenuList,
  NavigationMenuTrigger,
} from "@/components/dga/navigation-menu";

export function MainNavigation() {
  return (
    <NavigationMenu aria-label="الرئيسية">
      <NavigationMenuList>
        <NavigationMenuItem>
          <NavigationMenuLink variant="bar" href="/" active>
            الرئيسية
          </NavigationMenuLink>
        </NavigationMenuItem>
        <NavigationMenuItem>
          <NavigationMenuTrigger>الخدمات</NavigationMenuTrigger>
          <NavigationMenuContent>
            <NavigationMenuLink href="/traffic">
              <NavigationMenuLinkTitle>المرور</NavigationMenuLinkTitle>
              <NavigationMenuLinkDescription>الرخص والمخالفات.</NavigationMenuLinkDescription>
            </NavigationMenuLink>
          </NavigationMenuContent>
        </NavigationMenuItem>
      </NavigationMenuList>
    </NavigationMenu>
  );
}
```

استخدمها للروابط الرئيسية في موقع أو تطبيق يفتح بعضها لوحة من الروابط المتصلة. لرأس موقع كامل بشعاره وبحثه وقائمة جانبية على الهاتف استخدم [Header](/docs/components/header). يفتح الزر لوحته بالتمرير وبتركيز لوحة المفاتيح، ويفتحها مستخدم اللمس ولوحة المفاتيح بالنقر أو Enter. مرّر `active` لرابط الصفحة الحالية. كل نص ظاهر تمرّره أنت.

يُقرأ الشريط واللوحة من جهة البداية، فيكون العنصر الأول على اليمين بالعربية. ويتبادل اليمين واليسار، وتحاذي اللوحة حافة البداية لزرها.

## البنية [#anatomy]

- **التنقل** (`nav`): معلم في الصفحة. أعطه `aria-label`.
- **روابط الشريط وأزراره**: بارتفاع 40px، وحالات عنصر Header: التمرير والضغط والفتح والصفحة الحالية (تعبئة أساسية) وحلقة التركيز.
- **اللوحة**: سطح القائمة Menu في DGA (`background-menu` وحد 1px وانحناء radius-md و`shadow-2xl`). تشترك كل العناصر في لوحة واحدة فتنتقل وتتغير مقاساتها بينها.
- **روابط اللوحة**: أيقونة اختيارية وNavigationMenuLinkTitle وNavigationMenuLinkDescription. ويظهر عنوان الصفحة الحالية بخط عريض وتحته خط.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowLeft</kbd> | ينتقل بين عناصر الشريط (يتبادلان بالعربية). |
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>ArrowDown</kbd> | يفتح لوحة الزر المركَّز. |
| <kbd>Tab</kbd> | ينتقل من الزر إلى روابط لوحته ثم يتابع. |
| <kbd>Escape</kbd> | يغلق اللوحة ويعيد التركيز إلى زرها. |

- مبنية على Base UI Navigation Menu: معلم `nav` مع قائمة وأزرار بـ `aria-expanded` وروابط. وللصفحة الحالية `aria-current="page"`.
- لا يلزم التمرير أبدًا: تفتح كل لوحة بلوحة المفاتيح وبالنقر.
- النص بنسبة 4.5:1 والأيقونات والحلقات 3:1 أو أفضل في كل حالة، فاتحًا وداكنًا.

## الاشتقاق من DGA [#derivation-from-dga]

لا تعرّف DGA مكوّن قائمة تنقل. عناصر الشريط هي عناصر تنقل Header بارتفاع 40px، واللوحة هي سطح القائمة Menu في DGA بتخطيط روابط القائمة الفرعية في Header. ولا لون جديد فيها.
