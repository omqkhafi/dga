## الاستخدام [#usage]

```tsx title="page.tsx"
import { Avatar } from "@/components/dga/avatar";
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@/components/dga/hover-card";

export function Author() {
  return (
    <HoverCard>
      <HoverCardTrigger href="/authority">هيئة الحكومة الرقمية</HoverCardTrigger>
      <HoverCardContent>
        <Avatar initials="هـ" />
        <p>تقود التحول الرقمي للخدمات الحكومية.</p>
      </HoverCardContent>
    </HoverCard>
  );
}
```

استخدم Hover Card لمعاينة ملف شخصي أو خدمة أو تعريف دون مغادرة الصفحة. وهي تيسير لمن يستخدم المؤشر أو لوحة المفاتيح: **شاشات اللمس وقارئات الشاشة لا تحصل على البطاقة**، لذلك يجب أن يكون الزر رابطًا حقيقيًا إلى المحتوى نفسه، ولا يجوز أن تحمل البطاقة النسخة الوحيدة من أي شيء. وإن احتاج الناس إلى التفاعل مع المحتوى فاستخدم [Popover](/docs/components/popover). ولتلميح من سطر واحد استخدم [Tooltip](/docs/components/tooltip).

تفتح البطاقة أسفل الرابط وفي المنتصف افتراضيًا. وتتبادل `start` و`end` مع الاتجاه ويتبعهما السهم. ويُقرأ المحتوى داخل البطاقة باتجاه الصفحة.

## البنية [#anatomy]

- **الزر**: وسم `a` بنمط الرابط الأساسي في DGA: مسطّر و`link-primary` وبحالات Link للتمرير والضغط والتركيز.
- **البطاقة**: سطح Popover بعرض 320px: `background-menu` وحد بسمك 1px وانحناء radius-md و`shadow-2xl`.
- **السهم** (اختياري): نقطة Tooltip، بـ `showArrow`.
- **التوقيت**: تفتح بعد `delay` (400 مللي ثانية) وتغلق بعد `closeDelay` (200 مللي ثانية) من مغادرة المؤشر، ويُضبطان على الزر.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | تركيز الرابط يفتح البطاقة. والابتعاد عنه يغلقها. |
| <kbd>Escape</kbd> | يغلق البطاقة دون نقل التركيز. |
| <kbd>Enter</kbd> | على الرابط يتبعه كأي رابط. |

- تفتح البطاقة بتركيز لوحة المفاتيح كما بالتمرير، وتبقى مفتوحة ما دام المؤشر فوقها، ويغلقها Escape (WCAG 1.4.13: قابلة للإغلاق وللتمرير فوقها وثابتة).
- البطاقة معاينة وليست حوارًا: لا يعلنها قارئ الشاشة ولا يمكن الوصول إليها باللمس. ولهذا يجب أن يقود الرابط إلى المحتوى نفسه.
- النص بنسبة 4.5:1 وحلقة التركيز 3:1 أو أفضل، فاتحًا وداكنًا. ويحتفظ الرابط بخطه السفلي فلا يكون اللون الإشارة الوحيدة.
- تظهر بتلاشٍ وتكبير؛ ومع تقليل الحركة تظهر دون حركة.

## الاشتقاق من DGA [#derivation-from-dga]

لا تعرّف DGA بطاقة منبثقة، فهذا ليس مكوّنًا من DGA وليست له مواصفة منها. البطاقة هي سطح Popover أي سطح Menu في DGA، والزر هو الرابط الأساسي Link في DGA. ولا لون جديد فيه.
