## الاستخدام [#usage]

```tsx title="page.tsx"
import {
  Menubar,
  MenubarContent,
  MenubarItem,
  MenubarMenu,
  MenubarShortcut,
  MenubarTrigger,
} from "@/components/dga/menubar";

export function DocumentMenus() {
  return (
    <Menubar aria-label="المستند">
      <MenubarMenu>
        <MenubarTrigger>ملف</MenubarTrigger>
        <MenubarContent>
          <MenubarItem>
            طلب جديد <MenubarShortcut>⌘N</MenubarShortcut>
          </MenubarItem>
          <MenubarItem>فتح</MenubarItem>
        </MenubarContent>
      </MenubarMenu>
    </Menubar>
  );
}
```

استخدم شريط القوائم لأوامر تطبيق أو محرر، حيث ينتقل الناس عبر عدة قوائم. لقائمة واحدة خلف زر واحد استخدم [Menu](/docs/components/menu)، ولروابط الصفحات استخدم [Navigation Menu](/docs/components/navigation-menu). القوائم هي Menu في DGA، فتعمل العناصر والمجموعات وعناصر مربع الاختيار والراديو والقوائم الفرعية بالطريقة نفسها. كل نص ظاهر، ومنه الاختصارات، تمرّره أنت.

يُقرأ الشريط من جهة البداية، فيكون الزر الأول على اليمين بالعربية. ويتبادل اليمين واليسار، وتفتح القائمة محاذية لحافة البداية لزرها، وتفتح القائمة الفرعية في جهة النهاية (اليسار بالعربية) بسهم معكوس، وتبقى الاختصارات من اليسار إلى اليمين.

## البنية [#anatomy]

- **الشريط** (`role="menubar"`): `background-menu` وحد بسمك 1px وانحناء radius-md، بارتفاع 40px. مرّر له `aria-label`.
- **الزر** (`role="menuitem"` مع `aria-haspopup`): بارتفاع 32px، وحالات عنصر Header: التمرير والضغط والفتح وحلقة التركيز.
- **القائمة**: Menu في DGA، تفتح أسفل زرها في جهة البداية.
- **العناصر**: MenubarItem وMenubarCheckboxItem وMenubarRadioItem، مع MenubarGroup وMenubarLabel وMenubarSeparator وMenubarShortcut.
- **القائمة الفرعية**: MenubarSub مع MenubarSubTrigger وMenubarSubContent.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowLeft</kbd> | ينتقل إلى الزر التالي أو السابق (يتبادلان بالعربية). وإن كانت قائمة مفتوحة فتح قائمة الجار. |
| <kbd>ArrowDown</kbd> أو <kbd>Enter</kbd> أو <kbd>Space</kbd> | يفتح قائمة الزر المركَّز. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> | ينتقل بين العناصر. |
| <kbd>Home</kbd> / <kbd>End</kbd> | ينتقل إلى أول زر أو عنصر وآخره. |
| <kbd>ArrowRight</kbd> | يفتح قائمة فرعية (ArrowLeft بالعربية)؛ ويغلقها السهم المعاكس. |
| <kbd>Escape</kbd> | يغلق القائمة ويعيد التركيز إلى زرها. |

- مبني على Base UI Menubar وMenu: `role="menubar"` وعناصر `menuitem` و`menuitemcheckbox` و`menuitemradio`، مع `aria-expanded` على الأزرار.
- زر واحد فقط في ترتيب Tab، ويغادر Tab الشريط.
- النص بنسبة 4.5:1 والأيقونات والحلقات 3:1 أو أفضل في كل حالة، فاتحًا وداكنًا.
