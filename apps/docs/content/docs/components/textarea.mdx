## Usage

```tsx title="page.tsx"
import { Field, FieldDescription, FieldLabel } from "@/components/dga/field";
import { Textarea } from "@/components/dga/textarea";

export function DetailsField() {
  return (
    <Field name="details">
      <FieldLabel required>Request details</FieldLabel>
      <Textarea required rows={4} />
      <FieldDescription>Give the plot number and the street name.</FieldDescription>
    </Field>
  );
}
```

Use Textarea for answers that need more than a line: descriptions, comments, reasons. Set `rows` for the starting height. Tell people the limit in the helper text, and do not cut text off silently.

Text starts on the right and the resize handle sits in the bottom-left corner. Everything follows the page direction.

## Anatomy

- **Textarea** (`<textarea>`): the border, fill, text and resize handle in one element.
- The scroll bar is the browser's own; it appears when the text is taller than the box.

### Resizing

`resize="vertical"` (default) shows a handle at the end corner. Use `resize="none"` when the layout needs a fixed height. The field never resizes sideways.

```tsx title="page.tsx"
<Textarea resize="none" rows={6} />
```

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the field. |
| <kbd>Enter</kbd> | Starts a new line. |

- A native `<textarea>` linked to its [Field](/docs/components/field) label, helper text and error.
- Same states as [Input](/docs/components/input): the underline grows from the centre when pressed (half) and focused (full), and there is no outline. A wrapper `<div>` carries the border and underline because a `<textarea>` cannot draw one.
- The resize handle can be dragged with a pointer. Keyboard users get the same space by typing; give `rows` enough height for the expected answer.
- If you show a character limit, put it in the helper text and use `maxLength` so it is enforced.
