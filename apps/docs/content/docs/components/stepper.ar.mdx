## الاستخدام [#usage]

```tsx title="page.tsx"
import { Stepper, StepperItem } from "@/components/dga/stepper";

export function RequestSteps({ step }: { step: number }) {
  return (
    <Stepper aria-label="تقدّم الطلب" value={step}>
      <StepperItem title="البيانات" description="معلوماتك" />
      <StepperItem title="المستندات" description="ارفع الملفات" />
      <StepperItem title="المراجعة" description="تحقق وأكّد" />
    </Stepper>
  );
}
```

استخدم Stepper لعملية من ثلاث إلى سبع خطوات بترتيب ثابت، كنموذج على أجزاء. وهو يجمع Progress Indicator وRadial Stepper من DGA. وضع النموذج نفسه تحته. ولشريط يمتلئ باستمرار استخدم [Progress](/docs/components/progress).

## البنية [#anatomy]

- **الخطوة**: مؤشر بحجم 32px وعنوان ووصف اختياري، يصلها بالخطوة التالية خط بسمك 2px.
- **الحالات**: مكتملة (دائرة مملوءة وعلامة صح) وحالية (حلقة بلون العلامة) وقادمة (حلقة محايدة) وبها خطأ (دائرة حمراء مع تنبيه). تضبط `value` الخطوة الحالية، والخطوات قبلها مكتملة. واضبط `status` على خطوة لفرض حالة.
- **الرأسي**: تتراص المؤشرات ويمتد الخط على جهة البداية.
- **المضغوط** (تحت عرض `sm`): شكل Radial Stepper، حلقة فيها «2 من 4» واسم الخطوة والتالية.

### تفاعلي [#interactive]

مع `onValueChange` تكون الخطوات أزرارًا. وعطّل خطوة بـ `disabled` لمنع القفز إلى الأمام.

ترجم `labels` و`compactLabel` و`nextLabel`، ومرّر `formatNumber`، في الصفحات العربية. وضيّق المعاينة لترى الشكل المضغوط.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينتقل عبر الخطوات (في الخطوات التفاعلية فقط). |
| <kbd>Enter</kbd> | ينتقل إلى الخطوة المركَّزة. |
| <kbd>Space</kbd> | ينتقل إلى الخطوة المركَّزة. |

- قائمة مرتبة فيُعلَن الموضع. وللخطوة الحالية `aria-current="step"`، وتقرأ كل خطوة حالتها بالكلمات («مكتملة» و«الخطوة الحالية») إلى جانب اللون والأيقونة.
- الخطوط الواصلة زخرفة. وحلقات المؤشرات وتعبئاتها 3:1 والعناوين 4.5:1، فاتحًا وداكنًا.
- في الشكل المضغوط يكون اسم الخطوة منطقة حية مهذبة.
