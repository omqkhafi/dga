## Usage

```tsx title="page.tsx"
import { Button } from "@/components/dga/button";
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@/components/dga/empty";

export function NoRequests() {
  return (
    <Empty>
      <EmptyHeader>
        <EmptyMedia variant="icon">{/* an icon */}</EmptyMedia>
        <EmptyTitle>No requests yet</EmptyTitle>
        <EmptyDescription>Requests you submit appear here.</EmptyDescription>
      </EmptyHeader>
      <EmptyContent>
        <Button>New request</Button>
      </EmptyContent>
    </Empty>
  );
}
```

Use Empty when a whole area has nothing to show: no results, nothing created yet, a folder with no files, or an error that left the area empty. Say why and what to do next. The [Data Table](/docs/components/data-table) keeps its own compact empty row for a table; use Empty for the page or card around it.

## Anatomy

- **Media**: the icon in `icon-default-500`, or with `variant="icon"` on a 48px round `background-neutral-100` fill with an `icon-default` glyph.
- **Title**: `text-lg` semibold in `text-display`. It is a paragraph, so it fits under any heading level.
- **Description**: `text-md` in `text-primary-paragraph`. A link inside it takes the DGA link colour.
- **Content**: buttons or a field, centred below.
- **Border** (optional): `bordered` draws a dashed `border-neutral-primary` line, for an empty area inside a page.

## Accessibility

- Empty is plain content with no role. If it replaces results that were loading, announce the change with a live region in your page, such as an [Inline Alert](/docs/components/inline-alert) with `role="status"`.
- Decorative icons should be hidden from screen readers (`aria-hidden`).
- Text is 4.5:1 and icons 3:1 or better on every surface, in light and dark.

## Derivation from DGA

DGA has no standalone empty state; its Data Table has one empty row. This component keeps that row's icon, text colours and centring and adds the layout, the dashed border and the round icon fill. No colour is new.
