## الاستخدام [#usage]

```tsx title="layout.tsx"
import { DigitalStamp } from "@/components/dga/digital-stamp";
import { Header } from "@/components/dga/header";

export function SiteHeader() {
  return <Header stamp={<DigitalStamp domain="gov.sa" />} logo={<Logo />} items={items} />;
}
```

ضع الختم في أعلى كل صفحة من موقع حكومي، فوق [Second Nav](/docs/components/second-nav) و[Header](/docs/components/header): مرّره في خانة `stamp` من Header التي تقع فوق `top`. يخبر الزائر أن الموقع رسمي ويتيح له التحقق: العنوان ينتهي بنطاق سعودي، والاتصال HTTPS، والموقع مسجّل لدى هيئة الحكومة الرقمية. يقرأ الشريط «موقع حكومي مسجّل لدى هيئة الحكومة الرقمية.» مع الزر «كيف تعرف؟». لكل `domain` نصه الخاص؛ اضبطه على اللاحقة التي يستخدمها موقعك ومرّر `registrationNumber` للرابط في بطاقة التسجيل. كل نص خاصية بقيمة افتراضية بالإنجليزية؛ ترجمها في الصفحات العربية.

في العربية يبدأ العلم والنص من اليمين ويتبعهما المبدّل، وتجري البنود والبطاقة من اليمين. وتبقى لاحقة النطاق ورقم التسجيل من اليسار إلى اليمين ومعزولين عن العربية حولهما.

## البنية [#anatomy]

- **الشريط**: بارتفاع 32px، و`background-neutral-100`، ونص sm بوزن Medium، وحشوة `section-padding`. وفي الجوال يتراص النص والزر عموديًا.
- **العلم السعودي** (اختياري): يزيله `hideIcon`.
- **المبدّل**: زر حقيقي بـ `aria-expanded` و`aria-controls` يفتح اللوحة.
- **اللوحة**: بندان بأيقونة دائرية مؤطرة بـ `icon-success` وعنوان lg بوزن Semibold، ثم بطاقة التسجيل؛ وفي الجوال تتراص عموديًا. البند الأول هو جزء Extension في DGA: ينتهي عنوانه بلاحقة النطاق بالأخضر (`gov.sa` أو `edu.sa` أو `med.sa` أو `org.sa` أو `sch.sa` أو `.sa`)، ولكل لاحقة نصها. والثاني يشرح HTTPS.
- **بطاقة التسجيل**: شعار DGA و«مسجّل في هيئة الحكومة الرقمية:» ورقم التسجيل رابطًا (`registrationNumber` و`registrationHref`). مرّر `registrationLabel={null}` لحذف البطاقة.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينقل التركيز إلى المبدّل. |
| <kbd>Enter</kbd> أو <kbd>Space</kbd> | يفتح اللوحة أو يغلقها. |
| <kbd>Esc</kbd> | يغلق اللوحة ويُبقي التركيز على المبدّل. |

- الشريط منطقة لها تسمية. يعلن المبدّل `aria-expanded` ويشير إلى اللوحة بـ `aria-controls`؛ واللوحة المغلقة مخفية عن شجرة إمكانية الوصول.
- تُفتح اللوحة بلا حركة، فلا تحتاج إعدادات تقليل الحركة معالجة خاصة. ويُعطَّل دوران السهم مع تقليل الحركة.
- النص بتباين 4.5:1 على الشريط وكذلك المبدّل ولاحقة النطاق الخضراء ورابط التسجيل، مع حلقة تركيز 2px، في الفاتح والداكن.

## الاختلافات عن DGA [#deviations-from-dga]

- النصوص والتخطيط تتبع Digital Stamp في DGA. العلم وشعار DGA مرسومان من جديد بـ SVG مضمّن لأن الرسومات الرسمية ليست في السجل؛ استبدل الشعار عبر `registrationLogo`.
- في الجوال يتراص الشريط واللوحة عموديًا في مكوّن واحد بدل إطار جوال منفصل.
- جزء Extension صف في اللوحة، لا شريطًا مستقلًا بارتفاع 88px.
