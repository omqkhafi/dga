## الاستخدام [#usage]

```tsx title="layout.tsx"
import { YoutubeIcon, ZoomInAreaIcon } from "@hugeicons/core-free-icons";
import { Footer } from "@/components/dga/footer";

export function SiteFooter() {
  return (
    <Footer
      logo={<img src="/logo.svg" alt="الخدمات الرقمية" height={40} />}
      partnerLogos={<img src="/platforms.svg" alt="المنصات الوطنية" height={32} />}
      columns={[
        {
          title: "الخدمات",
          links: [
            { label: "تجديد ترخيص", href: "/renew" },
            { label: "سداد رسم", href: "/pay" },
          ],
        },
        { title: "الدعم", links: [{ label: "مركز المساعدة", href: "/help" }] },
      ]}
      socialTitle="وسائل التواصل الاجتماعي"
      social={[{ label: "يوتيوب", href: "https://youtube.com", icon: YoutubeIcon }]}
      accessibilityTitle="أدوات الوصول"
      accessibilityTools={[{ label: "تكبير", icon: ZoomInAreaIcon, onClick: () => {} }]}
      bottomLinks={[{ label: "خريطة الموقع", href: "/sitemap" }]}
      legalLinks={[
        { label: "الشروط والأحكام", href: "/terms" },
        { label: "سياسة الخصوصية", href: "/privacy" },
      ]}
      copyright="© ٢٠٢٦ الخدمات الرقمية. جميع الحقوق محفوظة."
    />
  );
}
```

كل نص خاصية، فترجم العناوين و`columnsLabel` و`socialLabel` و`bottomLabel` و`legalLabel` و`externalLabel` في الصفحات العربية. كل شيء يتبع الاتجاه: تقع الهوية عند حافة البداية وتمتد المجموعات منها.

## البنية [#anatomy]

- **التذييل**: رمادي (neutral-100) أو `tone="green"` (أخضر علم DGA مع نص على اللون). بحشوة 32px، والمحتوى في المنتصف بعرض 1280px ما لم تستخدم `fullWidth`.
- **الشعارات**: `logo`، و`partnerLogos` لشعارات المنصات، وتوضع دائمًا على لوح أبيض لتُقرأ على اللونين.
- **مجموعات الروابط** (`columns`): عنوان يعلوه فاصل وقائمة روابط؛ حتى أربع بالعرض، واثنتان بالعرض تحت `sm`.
- **وسائل التواصل الاجتماعي** (`social` و`socialTitle`): قسم بعنوان من روابط أيقونات بإطار.
- **أدوات الوصول** (`accessibilityTools` و`accessibilityTitle`): قسم بعنوان من أزرار أيقونات بإطار، مثل التكبير والتباين. الأداة زر، أو رابط بـ `href`، أو مفتاح تبديل بـ `pressed`.
- **الروابط السفلية** (`bottomLinks`): صف من روابط مسطّرة.
- **الصف القانوني** (`copyright` و`legalLinks`): حقوق النشر والشروط وسياسة الخصوصية، تحت خط. في المنتصف تحت `sm`.
- **اختياري**: `description` و`contact` و`badges` (شارات المتاجر) ليست من أجزاء DGA وهي مطفأة افتراضيًا.
- **الشاشات الصغيرة**: تبقى المجموعات مفتوحة في عمودين. يطويها `collapsible` في أكورديون بقسم لكل مجموعة.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينتقل بين الروابط بترتيب القراءة. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | يضغط زر أداة، أو يفتح قسم الأكورديون أو يغلقه حين يكون `collapsible` مفعّلًا. |

- معلم `footer`. أعمدة الروابط `nav` اسمه `columnsLabel`، والروابط السفلية `nav` اسمه `bottomLabel`، والروابط القانونية `nav` آخر اسمه `legalLabel`. لكل أداة اسم للوصول من `label`. بيانات التواصل قائمة، وتقرأ قارئات الشاشة نوع كل بيان.
- تفتح الروابط الخارجية في تبويب جديد وتعرض أيقونة وفيها ملاحظة لقارئ الشاشة (`externalLabel`).
- التركيز حدّ بسمك 2px: أسود على الرمادي وأبيض على الأخضر. النص 4.5:1 والأيقونات 3:1 في الفاتح والداكن.

## الاختلافات عن DGA [#deviations-from-dga]

- لا يُشحن العنوان بحجم 72px وفقرته بحجم 24px من CSS الخاص بـ DGA: للتذييل نص وصفي بخط Text md، وأنت تضع أي نص بارز بنفسك.
- الألوان رموز دلالية لا قيم مكتوبة يدويًا، فيعمل السمة الداكنة.
- يغيّر Figma الوزن فقط تحت 600px. هنا تصير المجموعات عمودين ويتوسط الصف القانوني؛ والأكورديون خيار (`collapsible`).
- أُضيفت اختياريًا الأجزاء: النص الوصفي وبيانات التواصل وشارات التطبيق.
