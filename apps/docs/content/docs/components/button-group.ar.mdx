## الاستخدام [#usage]

```tsx title="page.tsx"
import { Button } from "@/components/dga/button";
import { ButtonGroup } from "@/components/dga/button-group";

export function PageActions() {
  return (
    <ButtonGroup aria-label="إجراءات الصفحة">
      <Button variant="outline">حفظ</Button>
      <Button variant="outline">طباعة</Button>
      <Button variant="outline">مشاركة</Button>
    </ButtonGroup>
  );
}
```

Button Group تخطيط فقط: يحتفظ كل [Button](/docs/components/button) بإجرائه وحجمه ونمطه، وتزيل المجموعة الفراغ وتشارك الحواف. استخدمها لإجراءات مترابطة (حفظ وطباعة ومشاركة)، أو إجراء رئيسي بجوار خياراته (زر مقسوم مع [Menu](/docs/components/menu))، أو عنصر تحكم بالتكبير.

**أيها أستخدم؟** استخدم [Toggle Group](/docs/components/toggle-group) حين تُضغط الأزرار وتُحرر، و[Content Switcher](/docs/components/content-switcher) حين يكون خيار واحد مختارًا دائمًا ويبدّل العرض.

## البنية [#anatomy]

- **المجموعة**: `role="group"` تُسمّى بـ `aria-label`. الزوايا الخارجية وحدها مستديرة؛ والأزرار المتجاورة تتداخل 1px فلا تتضاعف الحدود.
- **ButtonGroupText**: مقطع غير تفاعلي (عدد أو تسمية) على `background-neutral-100` بحد.
- **ButtonGroupSeparator**: خط رفيع بين زرين لهما التعبئة نفسها، كالرئيسي والثانوي.

## RTL [#rtl]

الزر الأول في الجهة التي يبدأ منها النص، وتتبعه الزوايا الخارجية المستديرة، فلا يُعكس شيء يدويًا. وزر الخيارات في الزر المقسوم في النهاية، على اليسار في العربية، وتُفتح قائمته محاذية لتلك النهاية.

## إمكانية الوصول [#accessibility]

- دور `group` باسم برمجي. كل زر زر عادي في ترتيب Tab؛ ولا تضيف المجموعة سلوك لوحة مفاتيح من عندها.
- تُرفع الأزرار الممرَّر عليها والمركّز عليها والمضغوطة فوق جيرانها، فلا يُقصّ حد التركيز ولا الحدود.
- المقطع النصي 4.5:1 على تعبئته، فاتحًا وداكنًا.
