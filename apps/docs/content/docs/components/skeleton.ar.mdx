## الاستخدام [#usage]

```tsx title="page.tsx"
import { Skeleton } from "@/components/dga/skeleton";

<div aria-busy="true" aria-live="polite">
  <Skeleton shape="circle" size={48} />
  <Skeleton shape="line" size="lg" />
</div>
```

يعرض Skeleton شكل المحتوى أثناء تحميله، فلا تقفز الصفحة عند وصوله. اضبط العرض عبر `className` (مثل `w-32`).

## إمكانية الوصول [#accessibility]

- عناصر Skeleton مخفية عن قارئات الشاشة. اضبط `aria-busy="true"` على المنطقة التي تُحمَّل، وأزله عند وصول المحتوى.
- يتوقف النبض عند تفضيل تقليل الحركة.
