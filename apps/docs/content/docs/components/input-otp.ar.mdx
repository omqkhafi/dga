## الاستخدام [#usage]

```tsx title="page.tsx"
import { Field, FieldDescription, FieldLabel } from "@/components/dga/field";
import { InputOTP } from "@/components/dga/input-otp";

export function VerifyField() {
  return (
    <Field className="w-fit">
      <FieldLabel>رمز التحقق</FieldLabel>
      <InputOTP
        aria-label="رمز التحقق"
        slotLabel="الرقم {index} من {length}"
        groups={[3]}
        onValueComplete={(code) => verify(code)}
      />
      <FieldDescription>أرسلنا رمزًا من 6 أرقام إلى هاتفك.</FieldDescription>
    </Field>
  );
}
```

استخدمه لرمز قصير ينسخه الناس من رسالة أو يقرؤونه من تطبيق. وللنص الحر الأطول استخدم [Input](/docs/components/input). مرّر `aria-label` أو `aria-labelledby` لتسمية المجموعة، و`slotLabel` لترجمة اسم كل خانة. يُستدعى `onValueComplete` عند امتلاء كل الخانات أو لصق رمز كامل، فتتحقق دون زر.

تسير الخانات من اليسار إلى اليمين دائمًا، حتى في الصفحات العربية: هكذا تُقرأ الأرقام وتُرسل، مثل Number Input. وكل ما حولها (التسمية والنص المساعد والخطأ) يتبع اتجاه الصفحة. كتابة أرقام عربية هندية (٣) تملأ الخانة برقم غربي (3)، ولصق `٣٤٥٦٧٨` يفعل ذلك بالرمز كله.

## البنية [#anatomy]

- **الخانة**: صندوق Input من DGA (بارتفاع 32px أو 40px بحسب `size`)، واحدة لكل حرف، بالحد والخط السفلي وسلوك الخطأ نفسها.
- **الفاصل** (اختياري): شريط قصير بين المجموعات، يُضبط بـ `groups`.
- **النص المساعد** و**الخطأ**: من [Field](/docs/components/field).

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينقل إلى الرمز (أول خانة فارغة، ثم يخرج منه). |
| الأرقام | تملأ الخانة وتنتقل إلى التالية. |
| <kbd>Backspace</kbd> | يمسح الخانة، أو السابقة إن كانت فارغة، ويعود خطوة. |
| <kbd>←</kbd> <kbd>→</kbd> | تنقل بين الخانات. |
| <kbd>Ctrl</kbd> <kbd>V</kbd> | يلصق رمزًا على الخانات. |

- لكل خانة حقل نصي بـ `inputmode="numeric"` و`autocomplete="one-time-code"` فتقترح الهواتف رمز الرسالة. تُسمّى الخانة الأولى بتسمية Field (أو `aria-label` المجموعة)، وتُسمّى الخانات من الثانية إلى السادسة «الرقم 2 من 6» وهكذا (`slotLabel`)، فيعرف قارئ الشاشة موضعك دائمًا.
- المجموعة عنصر نموذج أصلي بحقل مخفي، فتُرسل وتُتحقق مثل أي حقل. ويضبط الخطأ `aria-invalid` على كل خانة.
- الحدود والخط السفلي وعلامة التركيز بنسبة 3:1 أو أفضل؛ والأرقام 4.5:1 أو أفضل على تعبئة الخانة، فاتحًا وداكنًا.

## الاشتقاق [#derivation]

لا توجد مواصفة من DGA للامتداد. الخانات هي صندوق Input من DGA (`cn-input`) بحالات التمرير والتركيز والضغط والخطأ والقراءة فقط والتعطيل دون تغيير، ومعالجة الأرقام تتبع Number Input. لا ألوان جديدة ولا رموز جديدة.
