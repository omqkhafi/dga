## الاستخدام [#usage]

```tsx title="page.tsx"
import { CheckmarkCircle02Icon } from "@hugeicons/core-free-icons";
import { HugeiconsIcon } from "@hugeicons/react";
import { FeaturedIcon } from "@/components/dga/featured-icon";

<FeaturedIcon variant="success">
  <HugeiconsIcon icon={CheckmarkCircle02Icon} />
</FeaturedIcon>
```

تلفت Featured Icon الانتباه إلى بطاقة أو حالة فارغة أو صندوق حوار، وتلمّح إلى معناه باللون.

ضعها في بداية البطاقة؛ وتحتاج الأيقونات الاتجاهية إلى `rtl:-scale-x-100`.

## البنية [#anatomy]

- **Root**: المربع أو الدائرة المظلَّلة.
- **Icon**: أي أيقونة من Hugeicons، بحجم يتناسب مع الحاوية (من 16 إلى 28px).

## أمثلة [#examples]

### المظهر واللون [#appearance-and-colour]

`light` تظليل خفيف، و`hard` تعبئة مصمتة، و`outlined` حلقة، بالألوان `brand` و`neutral` و`success` و`error` و`warning` و`info`. الأحجام من `sm` ‏32px إلى `xl` ‏56px؛ ويجعلها `circle` مستديرة.

## إمكانية الوصول [#accessibility]

- زخرفية افتراضيًا (`aria-hidden`)، لأن النص بجوارها يحمل المعنى.
- إذا كانت الأيقونة وحدها تحمل المعنى، مرّر `role="img"` و`aria-label`.
- تُفحص الأيقونات بنسبة 3:1 مقابل تعبئتها وسطح الصفحة.
