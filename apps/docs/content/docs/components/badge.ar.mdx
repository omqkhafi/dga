## الاستخدام [#usage]

```tsx title="page.tsx"
import { Badge } from "@/components/dga/badge";

<Badge variant="success">مقبول</Badge>
```

Badge تسمية قصيرة غير تفاعلية. للتسميات التي يمكن للمستخدم إزالتها أو اختيارها، استخدم [Tag](/docs/components/tag).

يتبع الحشو وموضع الأيقونة اتجاه القراءة.

## البنية [#anatomy]

- **Root**: عنصر `<span>`.
- **Icon** (اختيارية): قبل النص.
- **Label**: النص.

## أمثلة [#examples]

### الأحجام والشكل والأيقونات [#sizes-shape-and-icons]

ارتفاع `sm` ‏20px، و`md` ‏24px (الافتراضي)، و`lg` ‏32px. يجعله `rounded` على شكل حبة، وهو مناسب للأعداد. ويجعله `iconOnly` مربعًا (أو دائرة) ويحتاج إلى `aria-label`.

<Preview compact name="badge-sizes" title="الأحجام" />

## إمكانية الوصول [#accessibility]

- عنصر `<span>` بلا دور. يُقرأ النص في موضعه، فضع المعنى في النص لا في اللون وحده (WCAG 1.4.1).
- للعدد، أضف سياقًا: `<Badge>3<span className="sr-only"> غير مقروءة</span></Badge>`.
- تحتاج شارات الأيقونة فقط إلى `aria-label`، أو `aria-hidden` إذا كانت زخرفية.
