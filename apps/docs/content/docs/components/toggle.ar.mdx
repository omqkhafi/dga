## الاستخدام [#usage]

```tsx title="page.tsx"
import { Toggle } from "@/components/dga/toggle";

export function BoldToggle() {
  return (
    <Toggle aria-label="عريض" defaultPressed>
      عريض
    </Toggle>
  );
}
```

استخدم Toggle لخيار عرض أو تنسيق يسري لحظة الضغط ويمكن تحريره: عريض أو إظهار المرشحات أو العرض المضغوط. واستخدم [Switch](/docs/components/switch) لإعداد في نموذج، و[Checkbox](/docs/components/checkbox) لاختيار يُرسل مع النموذج، و[Button](/docs/components/button) لإجراء. ولعدة أزرار تبديل مترابطة استخدم [Toggle Group](/docs/components/toggle-group).

## البنية [#anatomy]

- هو زر Button: الارتفاعات نفسها (24 و32 و40px) والحواف والحشو وأحجام الأيقونات والنص.
- **المضغوط**: تعبئة الزر المحدد وحد داكن بسمك 1px، فلا تُعرف الحالة باللون وحده. وتنقلها `aria-pressed` للتقنيات المساعدة.

## RTL [#rtl]

زر التبديل متماثل، فلا ينعكس إلا ترتيب الأيقونة ونصها. والأيقونة الاتجاهية (كأيقونة المحاذاة) تُعكس بـ `rtl:-scale-x-100`.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينقل التركيز إلى الزر. |
| <kbd>Space</kbd> <kbd>Enter</kbd> | يضغطه أو يحرره. |

- زر `button` أصلي بـ `aria-pressed="true"` أو `"false"`. ويجب ألا يتغير اسمه مع الحالة: اكتب «عريض» لا «عريض مفعّل».
- الحد المضغوط 3:1 أو أفضل على الصفحة، والنصوص 4.5:1 على كل تعبئة، فاتحًا وداكنًا.
- التركيز هو حد الزر الأسود بسمك 2px. وتبقى حالة الضغط ظاهرة في الأزرار المعطلة.

## الاشتقاق [#derivation]

لا يوجد في DGA زر تبديل. هذا هو زر DGA بأنماط `aria-pressed` التي يعرّفها أصلًا، مع حد داكن لحالة الضغط لأن تعبئة التحديد وحدها 1.2:1 على الصفحة في الوضع الفاتح. لا ألوان جديدة.
