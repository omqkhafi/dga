## الاستخدام [#usage]

```tsx title="page.tsx"
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/dga/table";

export function Requests() {
  return (
    <Table aria-label="الطلبات">
      <TableHeader>
        <TableRow>
          <TableHead>الطلب</TableHead>
          <TableHead>الخدمة</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        <TableRow>
          <TableCell>طلب-١٠٠١</TableCell>
          <TableCell>تجديد رخصة تجارية</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  );
}
```

استخدم الجدول لبيانات يقارنها الناس عبر الصفوف والأعمدة. وهو HTML عادي فلا يحتاج إلى JavaScript. وللترتيب والتصفية والتحديد والترقيم استخدم [Data Table](/docs/components/data-table). ولقائمة قصيرة من الحقائق استخدم [Structured List](/docs/components/list).

## البنية [#anatomy]

- **Table**: داخل منطقة تمرير. نص Text md بلون `table-text-body`، وحشو الخلايا من `table-cell-*-padding`.
- **الرأس** (`TableHeader`): ارتفاعه 48px، بخط Text xs وبوزن Medium ولون `table-text-head` على `table-background-header`.
- **الصف**: 64px (و48px مضغوطًا). وللصفوف عند المرور والمتبادلة والمحددة رموز `table-background-*`.
- **أنواع الخلايا**: نص ورابط ووسم وحالة وصورة شخصية وخانة اختيار ومفتاح وإجراءات وأيقونة تقييم وأي محتوى مخصص. انظر المثال أدناه.
- **زرا الترتيب والتصفية**: زران بحجم 20px في العنوان، يصيران أسودين عند التفعيل.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينتقل إلى محتوى الخلية التالي القابل للتركيز، كرابط أو خانة أو زر. |
| <kbd>Enter</kbd> | يضغط زر ترتيب أو تصفية مركَّزًا. |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowRight</kbd> | يمرّر جدولًا عريضًا مركَّزًا أفقيًا. |

- عناصر دلالية `table` و`thead` و`tbody` و`th` مع `scope`، مع `caption` أو `aria-label` لتسميته.
- يحمل العنوان المرتّب `aria-sort`؛ وزرا الترتيب والتصفية مسمّيان بـ `aria-label`.
- نص المتن بنسبة 4.5:1 على الصف والصف المتبادل والمرور والمحدد، وكذلك الرابط الأساسي، فاتحًا وداكنًا.
