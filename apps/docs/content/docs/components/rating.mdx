## Usage

```tsx title="page.tsx"
import { useState } from "react";
import { Rating } from "@/components/dga/rating";

export function RateService() {
  const [value, setValue] = useState(0);
  return <Rating aria-label="Rate this service" value={value} onValueChange={setValue} />;
}
```

Use a rating to ask how satisfied someone was, and to show the result. Pair it with a way to say why when the score is low. Use `readOnly` to display a score (an average, or a submitted answer). Add `allowHalf` when the score needs half stars; a read-only rating also draws a fractional value such as 4.3.

The first star is on the start side: in Arabic it is on the right, the fill grows from the right (a half star fills its right half) and the left arrow raises the rating.

## Anatomy

- **Stars**: five, 24, 32 or 48px, 4px apart (`size` `sm`, `md`, `lg`).
- **Colour**: `background-secondary` (gold) or, with `brand`, `background-primary`. Every star is outlined so its shape is clear.
- **Half star**: with `allowHalf` each star has a start half and an end half; the start half fills first.
- **States**: hover previews the rating, pressing shrinks the star slightly, and the chosen star has a heavier outline; focus shows a ring.
- **Interactive**: a radio group (two radios per star with `allowHalf`).
- **Read-only**: an image with a text alternative, "Rated 4 out of 5".

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves into the rating (to the chosen star, or the first), then out. |
| <kbd>ArrowRight</kbd> | Chooses the next star (the previous one in Arabic). |
| <kbd>ArrowLeft</kbd> | Chooses the previous star (the next one in Arabic). |
| <kbd>Space</kbd> | Chooses the focused star. |

With `allowHalf` each arrow key moves by half a star.

- Built on Base UI Radio Group: a `radiogroup` of radios named "1 star", "2 stars" and so on ("2.5 stars" with `allowHalf`), with one in the tab order.
- A read-only rating is an `img` named by `summaryLabel`, so the score is never only in the stars.
- The star outline is 3:1 on the page in light and dark, so the shape is clear although the gold fill alone is 2.30:1.

## Deviations from DGA

- The CSS colours the stars `#faaf00` and Figma uses `background-secondary` (2.30:1). Stars are outlined to reach 3:1.
- DGA defines half stars and pressed and selected states; they are built here. The pressed look (scale to 90%) and the selected look (2px outline instead of 1.5px) are our reading of them. Keyboard, hover and focus are added.
