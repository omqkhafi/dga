## الاستخدام [#usage]

```tsx title="page.tsx"
"use client";

import { Bar, BarChart, CartesianGrid, XAxis, YAxis } from "recharts";
import {
  CHART_SERIES,
  type ChartConfig,
  ChartContainer,
  ChartLegend,
  ChartLegendContent,
  ChartTooltip,
  ChartTooltipContent,
  useChartDirection,
} from "@/components/dga/chart";

const data = [
  { month: "يناير", applications: 186, renewals: 80 },
  { month: "فبراير", applications: 305, renewals: 200 },
];
const config = {
  applications: { label: "الطلبات", color: CHART_SERIES[0] },
  renewals: { label: "التجديدات", color: CHART_SERIES[1] },
} satisfies ChartConfig;

export function Requests() {
  const { xAxisProps, yAxisProps } = useChartDirection();
  return (
    <ChartContainer
      config={config}
      title="الطلبات والتجديدات حسب الشهر"
      description="تبلغ الطلبات ذروتها في فبراير عند 305."
      table={{ data, categoryKey: "month", categoryLabel: "الشهر" }}
    >
      <BarChart data={data}>
        <CartesianGrid vertical={false} />
        <XAxis dataKey="month" {...xAxisProps} />
        <YAxis {...yAxisProps} />
        <ChartTooltip content={<ChartTooltipContent />} />
        <ChartLegend content={<ChartLegendContent />} />
        <Bar dataKey="applications" fill="var(--color-applications)" />
        <Bar dataKey="renewals" fill="var(--color-renewals)" />
      </BarChart>
    </ChartContainer>
  );
}
```

يغلّف ChartContainer مخططًا واحدًا من Recharts. يعطي `config` كل سلسلة تسمية ولونًا، ويكشف اللون باسم `--color-<key>`. وكل ما بداخله Recharts عادي، فيعمل أي مخطط أو مكوّن منها. استخدم المخطط لإظهار اتجاه أو مقارنة أو حصة. وأعطِ كل مخطط `title` و`description` وبياناته في `table`.

يعيد `useChartDirection` الخصائص التي ترتب المخطط بحسب اتجاه القراءة. بالعربية تقع الفئة الأولى إلى اليمين، ويقع المحور الرأسي إلى اليمين، وتدور الدائرة عكس عقارب الساعة. وزّع `xAxisProps` على XAxis و`yAxisProps` على YAxis و`pieProps` على Pie. ويتبع التلميح ووسيلة الإيضاح الاتجاه. وتبقى الأرقام غربية من اليسار إلى اليمين، فلا تُقرأ `1,200` على أنها `0021,`.

## البنية [#anatomy]

- **ChartContainer**: يسمّي المخطط ويطبّق الألوان ويعرض الجدول الاختياري وزره.
- **ChartTooltip** مع **ChartTooltipContent**: سطح Card في DGA، وعنوان، وصف لكل سلسلة بعلامتها، والقيمة.
- **ChartLegend** مع **ChartLegendContent**: علامة وتسمية لكل سلسلة.
- **الجدول**: يعرض `table` الأرقام نفسها جدولًا. يضيف `tableMode="toggle"` (الافتراضي) زر «عرض كجدول»، ويبقيه `"hidden"` لقارئات الشاشة فقط، ويحذفه `"none"`.
- **ChartDot** و**ChartSwatch**: أشكال العلامات (دائرة ومربع ومثلث ومعيّن) للخطوط ووسيلة الإيضاح والتلميح.

## لوحة ألوان المخططات في DGA [#the-dga-chart-palette]

ترسم DGA مخططاتها بألوان `charts-*` (الأخضر والذهبي والأزرق واللافندر والأحمر والأصفر). في الوضع الفاتح لا تتجاوز نسبتها 1.3:1 إلى 2.8:1 مع الأبيض، وهي دون 3:1 التي تحتاجها علامة المخطط، فيستعمل المخطط أربعة رموز مصحّحة هي `chart-series-1` إلى `chart-series-4` (`CHART_SERIES`) بدرجات الأخضر والذهبي واللافندر والأزرق. كل منها مبني من تدرجات الألوان نفسها وبنسبة 3:1 أو أفضل مع كل أسطح الصفحة ومع السلسلة المجاورة (1 و2، و2 و3، و3 و4، و4 و1)، فاتحًا وداكنًا. السلسلتان 1 و3 هما الزوج الداكن و2 و4 الزوج الفاتح، فيختلف الجاران في السطوع لا في الصبغة وحدها. أما السلسلتان المتباعدتان (1 و3، و2 و4) فهما في نطاق سطوع واحد: تختلف الخطوط أيضًا بشكل العلامة والتقطيع، ويُميَّز العمود أو المساحة أو شريحة الدائرة بموضعه وتسميته ووسيلة الإيضاح.

## إمكانية الوصول [#accessibility]

- افتراضيًا يكون المخطط صورة للتقنيات المساعدة: `role="img"` يسمّيه `title` ويصفه `description`. اذكر في الوصف الاتجاه أو أكبر قيمة، ويحمل الجدول الأرقام.
- مع `interactive` يكون المخطط بالدور `role="group"` ووصف دور «مخطط»؛ تنتقل مفاتيح الأسهم بين النقاط ويظهر إطار تركيز بسمك 2px.
- لزر «عرض كجدول» الخاصيتان `aria-expanded` و`aria-controls`.
- السلاسل 3:1 مع الصفحة ومع بعضها، ونص المحاور ووسيلة الإيضاح والتلميح 4.5:1. ولا يكون اللون الإشارة الوحيدة: تكررها العلامات والتقطيع والتسميات والجدول.
- يتوقف التحريك حين يفضّل الشخص تقليل الحركة (`useChartAnimation`).

## الاختلافات عن DGA [#deviations-from-dga]

- يرسم Figma المخططات الدائرية (بثقب ودونه) والخطية والأعمدة صورًا مع وسيلة إيضاح وتسميات للمحاور. تتبع الحاوية والتلميح ووسيلة الإيضاح هنا مخطط shadcn على Recharts؛ أما سطح التلميح وألوان النص وحلقة التركيز فمن DGA.
- أربع سلاسل لونية بدل ست في DGA (`charts-*`)، مصحّحة للتباين (انظر الإدخالات أدناه). ولم تُرسم السلسلتان الخامسة والسادسة.
- أُضيف مخطط المساحة ووضع لوحة المفاتيح وجدول البيانات البديل.
