## الاستخدام [#usage]

```tsx title="page.tsx"
import { Field, FieldLabel } from "@/components/dga/field";
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
  InputGroupText,
} from "@/components/dga/input-group";

export function AmountField() {
  return (
    <Field>
      <FieldLabel>المبلغ</FieldLabel>
      <InputGroup>
        <InputGroupAddon>
          <InputGroupText>ر.س</InputGroupText>
        </InputGroupAddon>
        <InputGroupInput inputMode="decimal" dir="ltr" />
      </InputGroup>
    </Field>
  );
}
```

لأيقونة واحدة أو بادئة قصيرة، لدى [Input](/docs/components/input) أصلًا `startAdornment` و`endAdornment`. استخدم Input Group حين تحتاج إلى عدة إضافات أو زر داخل الحقل أو تلميح لوحة مفاتيح. وضع [Button](/docs/components/button) (`size="sm"` و`variant="subtle"` أو `primary`) داخل `InputGroupAddon` لإجراء، وأعطِ الزر بأيقونة فقط `aria-label`.

تقع الإضافات في الجهة التي يبدأ منها النص وينتهي: البادئة على اليمين في العربية، والزر الأخير على اليسار. وتُضبط الأرقام والمبالغ وأرقام الهواتف على `dir="ltr"` لتحتفظ بترتيبها، و`InputGroupKbd` من اليسار إلى اليمين دائمًا.

## البنية [#anatomy]

- **المجموعة**: صندوق Input بارتفاع 32px (`md`) أو 40px (`lg`)، بالتعبئة الافتراضية أو الفاتحة أو الداكنة.
- **InputGroupInput**: حقل النص الذي يسمّيه [Field](/docs/components/field) ويصفه ويتحقق منه.
- **InputGroupAddon**: أيقونة أو نص أو `Kbd` أو Button، في بداية الحقل أو نهايته.

## إمكانية الوصول [#accessibility]

- التركيز هو تركيز Input: ينمو الخط السفلي من المنتصف ويغمق الحد ويلقي الصندوق ظل التركيز. لا حد إضافي؛ تضيء المجموعة كلها حين يكون التركيز على الحقل أو على زر داخلها.
- الأيقونات الزخرفية `aria-hidden`؛ والنصوص في الإضافات تُقرأ جزءًا من المجموعة. أعطِ تسمية Field للحقل لا للإضافة.
- للمجموعة `role="group"`. ويضبط الخطأ `aria-invalid` على الحقل والحد الأحمر على المجموعة.
- الأرقام 4.5:1، والحد والخط السفلي 3:1، وأيقونات الإضافات 3:1 على التعبئة، فاتحًا وداكنًا.
