## Usage

```tsx title="page.tsx"
import { Button } from "@/components/dga/button";
import { ButtonGroup } from "@/components/dga/button-group";

export function PageActions() {
  return (
    <ButtonGroup aria-label="Page actions">
      <Button variant="outline">Save</Button>
      <Button variant="outline">Print</Button>
      <Button variant="outline">Share</Button>
    </ButtonGroup>
  );
}
```

A Button Group is only layout: every [Button](/docs/components/button) keeps its own action, size and variant, and the group removes the gap and shares the edges. Use it for actions that belong together (Save, Print, Share), a primary action next to its options (a split button with a [Menu](/docs/components/menu)), or a zoom control.

**Which one?** Use [Toggle Group](/docs/components/toggle-group) when the buttons are pressed on and off, and [Content Switcher](/docs/components/content-switcher) when exactly one option is always chosen and switches the view.

## Anatomy

- **Group**: `role="group"`, named with `aria-label`. Only the outer corners are rounded; neighbouring buttons overlap by 1px so borders are not doubled.
- **ButtonGroupText**: a non-interactive segment (a count, a label) drawn on `background-neutral-100` with a border.
- **ButtonGroupSeparator**: a thin line between two buttons that share a fill, such as primary and secondary.

## RTL

The first button is on the side where the text starts, and the rounded outer corners follow, so nothing is mirrored by hand. A split button's options button sits at the end, on the left in Arabic, and its menu opens aligned to that end.

## Accessibility

- A `group` role with an accessible name. Each button is a normal button in the tab order; the group adds no keyboard behaviour of its own.
- Hover, focused and pressed buttons are raised above their neighbours, so the focus outline and borders are never clipped.
- The text segment is 4.5:1 on its fill, in light and dark.
