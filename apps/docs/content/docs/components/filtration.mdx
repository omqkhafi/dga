It installs the [Button](/docs/components/button), [Checkbox](/docs/components/checkbox), [Date Picker](/docs/components/date-picker), [Dialog](/docs/components/dialog), [Drawer](/docs/components/drawer), [Input](/docs/components/input), [Radio](/docs/components/radio), [Rating](/docs/components/rating), [Search Box](/docs/components/search-box), [Select](/docs/components/select) and [Tag](/docs/components/tag) with it. Each group type is built from one of them, so you use only what your groups need.

## Usage

```tsx title="page.tsx"
import { useState } from "react";
import { Filtration, type FiltrationValue } from "@/components/dga/filtration";

export function Services({ services }: { services: Service[] }) {
  const [value, setValue] = useState<FiltrationValue>({});
  const shown = applyFilters(services, value);
  return (
    <Filtration
      groups={[
        {
          id: "city",
          type: "checkbox",
          label: "City",
          options: [
            { value: "riyadh", label: "Riyadh" },
            { value: "jeddah", label: "Jeddah" },
          ],
        },
        { id: "q", type: "input", label: "Keyword" },
      ]}
      value={value}
      onValueChange={setValue}
      resultCount={shown.length}
    >
      <ServiceList services={shown} />
    </Filtration>
  );
}
```

`Filtration` only holds the filters: you filter your own data with `value`. It is controlled with `value` and `onValueChange`, or uncontrolled with `defaultValue`. The value has one entry per group `id`: a list of values for checkboxes, one value for a radio group, a select, a rating (the stars, such as `"4"`) or a date, text for an input, and `[min, max]` for a range or a date range (`[start, end]`). Empty entries are left out.

Every visible text is a prop: `title`, `clearAllLabel`, `appliedLabel`, `removeLabel`, `triggerLabel`, `applyLabel`, `resultLabel` and `closeLabel`, and the labels of the groups and options.

The panel sits at the start side of the results, the Drawer opens from the start with `drawerSide="start"`, and the Tags run from the start.

## Anatomy

- **Panel**: 288px beside the results from the `lg` width. Groups of `checkbox`, `radio`, `select`, `input`, `range`, `date`, `rating` and `custom`, 24px apart.
- **Searchable options**: `searchable` on a checkbox or radio group adds a [Search Box](/docs/components/search-box) that narrows the list as you type, with `noMatchLabel` when nothing matches.
- **Show more**: `initialCount` shows that many options and a "Show more" button (`showMoreLabel`, `showLessLabel`) for the rest.
- **Date**: a [Date Picker](/docs/components/date-picker), single or `mode="range"`; pass its own props (labels, numerals, min, max) in `datePickerProps`.
- **Rating**: [Rating](/docs/components/rating) stars; the value is the number of stars and the tag reads "4 stars and up".
- **Custom**: `type: "custom"` with a `render` function that gets `value` and `onValueChange`, for any control you draw. It joins the tags and the clear-all button like the others.
- **Applied filters**: a removable [Tag](/docs/components/tag) for each chosen option, text or range, with a clear-all button.
- **Result count** (`resultCount`): above the results, announced when it changes.
- **Small screens**: below `lg` a button with the number of filters opens the same panel in a [Drawer](/docs/components/drawer) from `drawerSide` (`start` or `end`), with a button that shows the results.
- **Placement** (`placement`, DGA: Placement): `inline` (default) is the layout above. `start` and `end` always show the button and open the panel anchored to that side in a Drawer; `center` opens it in a centred [Dialog](/docs/components/dialog).

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves through the groups, the tags and the buttons. |
| <kbd>Space</kbd> | Toggles a checkbox or chooses a radio. |
| <kbd>Up</kbd> / <kbd>Down</kbd> | Moves inside a radio group or the select list. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | On a tag, its remove button removes the filter. |

- The panel is an `aside` named by `title`. Checkbox, radio and range groups are `fieldset` elements with a `legend`; the select and the input have a label.
- Each remove button is named, for example "Remove Riyadh" (`removeLabel`). The result count is a status region, so a screen reader hears the new count.
- The search field and the "Show more" button (`aria-expanded`) are reachable with <kbd>Tab</kbd>. The Drawer and the Dialog trap focus and return it to the button. Text is 4.5:1 and every control keeps its own contrast.

## Deviations from DGA

- Figma has the trigger button only (Open, Result, Show Results and the Left, Center and Right placement). The panel, the Tags, the Drawer and the Dialog are composed here from the DGA components, and the Left and Right placements are the logical `start` and `end` so they mirror in RTL.
- Search, Show more, date, rating and custom groups come from the Figma sub-parts (`_Filtration list`, `_Multi Select Checkbox Filter`, `_Text Range`) and the DGA Search Box, Date Picker and Rating; they are all optional.
