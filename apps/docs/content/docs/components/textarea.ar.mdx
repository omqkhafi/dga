## الاستخدام [#usage]

```tsx title="page.tsx"
import { Field, FieldDescription, FieldLabel } from "@/components/ui/field";
import { Textarea } from "@/components/ui/textarea";

export function DetailsField() {
  return (
    <Field name="details">
      <FieldLabel required>تفاصيل الطلب</FieldLabel>
      <Textarea required rows={4} />
      <FieldDescription>اذكر رقم القطعة واسم الشارع.</FieldDescription>
    </Field>
  );
}
```

استخدم Textarea للإجابات التي تحتاج أكثر من سطر: الأوصاف والتعليقات والأسباب. اضبط `rows` للارتفاع الابتدائي. اذكر الحد الأقصى في النص المساعد، ولا تقتطع النص بصمت.

## البنية [#anatomy]

- **Textarea** (`<textarea>`): الحد والتعبئة والنص ومقبض تغيير الحجم في عنصر واحد.
- شريط التمرير هو شريط المتصفح نفسه؛ يظهر عندما يزيد النص عن ارتفاع الصندوق.

## أمثلة [#examples]

### الحالات [#states]

الافتراضية والمعبأة وللقراءة فقط والمعطّلة وحالة الخطأ، مع التعبئة الأغمق دون تغيير الحجم.

<Preview name="textarea-states" title="الحالات" />

### تغيير الحجم [#resize]

`resize="vertical"` (الافتراضي) يعرض مقبضًا في زاوية النهاية. استخدم `resize="none"` عندما يتطلب التخطيط ارتفاعًا ثابتًا. ولا يتغير عرض الحقل جانبيًا أبدًا.

```tsx title="page.tsx"
<Textarea resize="none" rows={6} />
```

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينقل التركيز إلى الحقل. |
| <kbd>Enter</kbd> | يبدأ سطرًا جديدًا. |

- عنصر `<textarea>` أصلي مرتبط بتسمية [Field](/docs/components/field) ونصه المساعد وخطئه.
- الحالات نفسها كما في [Input](/docs/components/input): ينمو الخط السفلي من الوسط عند الضغط (نصفًا) وعند التركيز (كاملًا)، ولا يوجد حد خارجي. ويحمل عنصر `<div>` الغلاف الحد والخط السفلي لأن `<textarea>` لا يستطيع رسمهما.
- يمكن سحب مقبض تغيير الحجم بالمؤشر. ويحصل مستخدمو لوحة المفاتيح على المساحة نفسها بالكتابة؛ أعطِ `rows` ارتفاعًا يكفي للإجابة المتوقعة.
- إن عرضت حدًا للأحرف فضعه في النص المساعد واستخدم `maxLength` ليُفرض.
