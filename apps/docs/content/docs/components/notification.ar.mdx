## الاستخدام [#usage]

```tsx title="page.tsx"
import { Notification } from "@/components/dga/notification";

export function MaintenanceNotice() {
  return (
    <Notification
      variant="warning"
      title="تنبيه:"
      dismissible
      dismissLabel="تجاهل"
      action={<a href="/status">التفاصيل</a>}
    >
      ستتوقف البوابة للصيانة يوم الجمعة.
    </Notification>
  );
}
```

استخدم Notification في أعلى صفحة أو قسم لما يخصها كلها: صيانة مجدولة أو خدمة جديدة أو مشكلة في الحساب. ويبقى حتى يتجاهله الشخص أو يزول سببه. ولرسالة تخص نموذجًا أو بطاقة واحدة استخدم [Inline Alert](/docs/components/inline-alert)؛ وللحدث الذي وقع للتو استخدم [Toast](/docs/components/toast). أضف Notification عند انطباقه لا قبله: فالمنطقة الحية تُعلَن عند ظهور محتواها. وابدأه بـ `title` قصير بخط عريض («مهم:»).

الأيقونة على اليمين، والإجراء وزر الإغلاق على اليسار، ويبدأ النص من اليمين. ولا شيء يُعكس يدويًا.

## البنية [#anatomy]

- **الشريط** (`role="status"` أو `role="alert"` لـ `critical`): بعرض كامل وحشوة 8 في 24px وانحناء radius-xs وحد سفلي بسمك 2px بلون النوع.
- **الأيقونة** (اختيارية) و**العنوان** (نص افتتاحي بخط عريض) والرسالة.
- **الإجراء** (رابط أو Button صغير) و**زر الإغلاق**، في جهة النهاية.

## أمثلة [#examples]

### الأنواع [#kinds]

قيمة `variant` هي `neutral` أو `info` أو `success` أو `warning` أو `critical`. ولكل نوع تظليل 50 ونص وأيقونة بلونه. تجاهل أحدها لتراه يزول.

<Preview compact name="notification-kinds" title="الأنواع" />

### دون أيقونة ومُغلق [#without-an-icon-and-dismissed]

تزيل `hideIcon` أيقونة الحالة: ويبقى اللون والعنوان العريض حاملين للنوع. وبعد أن يغلق الشخص الإشعار تُستدعى `onDismiss` ولا يُعرض شيء مكانه، فاحتفظ بالحالة في الصفحة إن أردت إعادته.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينقل التركيز إلى الإجراء ثم إلى زر الإغلاق. |
| <kbd>Enter</kbd> | يضغط الرابط أو الزر المركَّز. |
| <kbd>Space</kbd> | يضغط الزر المركَّز. |

- منطقة حية: لـ `critical` الدور `role="alert"` ويقاطع؛ وغيره `role="status"` وينتظر فاصلًا. ولا يتحرك التركيز.
- يظهر النوع من الأيقونة والنص الافتتاحي إضافة إلى اللون. والنص بنسبة 4.5:1 والأيقونات 3:1 أو أفضل على التظليل، فاتحًا وداكنًا.
- لزر الإغلاق اسم (`dismissLabel`) وحد تركيز بسمك 2px. وتحتفظ الروابط في الرسالة بخطها السفلي.
