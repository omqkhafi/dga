## الاستخدام [#usage]

```tsx title="page.tsx"
import { useState } from "react";
import { Filtration, type FiltrationValue } from "@/components/dga/filtration";

export function Services({ services }: { services: Service[] }) {
  const [value, setValue] = useState<FiltrationValue>({});
  const shown = applyFilters(services, value);
  return (
    <Filtration
      groups={[
        {
          id: "city",
          type: "checkbox",
          label: "المدينة",
          options: [
            { value: "riyadh", label: "الرياض" },
            { value: "jeddah", label: "جدة" },
          ],
        },
        { id: "q", type: "input", label: "كلمة مفتاحية" },
      ]}
      value={value}
      onValueChange={setValue}
      resultCount={shown.length}
    >
      <ServiceList services={shown} />
    </Filtration>
  );
}
```

لا يحمل `Filtration` سوى المرشحات: أنت تصفّي بياناتك بـ `value`. يعمل بتحكم خارجي عبر `value` و`onValueChange`، أو دون تحكم عبر `defaultValue`. للقيمة إدخال لكل `id` مجموعة: قائمة قيم لخانات الاختيار، وقيمة واحدة لأزرار الاختيار أو القائمة المنسدلة أو التقييم (عدد النجوم، مثل `"4"`) أو التاريخ، ونص للحقل، و`[min, max]` للنطاق أو لنطاق التاريخ (`[start, end]`). تُترك الإدخالات الفارغة.

كل نص ظاهر خاصية: `title` و`clearAllLabel` و`appliedLabel` و`removeLabel` و`triggerLabel` و`applyLabel` و`resultLabel` و`closeLabel`، وتسميات المجموعات والخيارات.

اللوحة عند بداية النتائج، ويُفتح الدرج من البداية مع `drawerSide="start"`، وتجري الوسوم من البداية.

## البنية [#anatomy]

- **اللوحة**: بعرض 288px بجانب النتائج من عرض `lg`. مجموعات `checkbox` و`radio` و`select` و`input` و`range` و`date` و`rating` و`custom`، بينها 24px.
- **خيارات قابلة للبحث**: `searchable` على مجموعة خانات أو أزرار اختيار يضيف [Search Box](/docs/components/search-box) يضيّق القائمة أثناء الكتابة، مع `noMatchLabel` عند عدم وجود تطابق.
- **عرض المزيد**: يعرض `initialCount` هذا العدد من الخيارات وزر «عرض المزيد» (`showMoreLabel` و`showLessLabel`) لبقيتها.
- **التاريخ**: [Date Picker](/docs/components/date-picker) مفرد أو `mode="range"`؛ ومرّر خصائصه (التسميات والأرقام وmin وmax) في `datePickerProps`.
- **التقييم**: نجوم [Rating](/docs/components/rating)؛ القيمة عدد النجوم، ويقرأ الوسم «4 نجوم فأكثر».
- **مخصص**: `type: "custom"` مع دالة `render` تستلم `value` و`onValueChange`، لأي عنصر تحكم ترسمه. ينضم إلى الوسوم وزر مسح الكل مثل غيره.
- **المرشحات المطبّقة**: [Tag](/docs/components/tag) قابل للإزالة لكل خيار أو نص أو نطاق مختار، مع زر مسح الكل.
- **عدد النتائج** (`resultCount`): فوق النتائج، ويُعلَن عند تغيّره.
- **الشاشات الصغيرة**: تحت `lg` يفتح زر فيه عدد المرشحات اللوحة نفسها في [Drawer](/docs/components/drawer) من `drawerSide` (`start` أو `end`)، مع زر يعرض النتائج.
- **الموضع** (`placement`، DGA: Placement): `inline` (الافتراضي) هو التخطيط أعلاه. يعرض `start` و`end` الزر دائمًا ويفتحان اللوحة مثبّتة على تلك الجهة في درج؛ ويفتحها `center` في [Dialog](/docs/components/dialog) في الوسط.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينتقل بين المجموعات والوسوم والأزرار. |
| <kbd>Space</kbd> | يبدّل خانة الاختيار أو يختار زر اختيار. |
| <kbd>Up</kbd> / <kbd>Down</kbd> | يتحرك داخل مجموعة أزرار الاختيار أو القائمة المنسدلة. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | على الوسم، يزيل زر الإزالة المرشح. |

- اللوحة عنصر `aside` يسميه `title`. مجموعات خانات الاختيار وأزرار الاختيار والنطاق عناصر `fieldset` بـ `legend`؛ وللقائمة المنسدلة والحقل تسمية.
- لكل زر إزالة اسم، مثل «إزالة الرياض» (`removeLabel`). عدد النتائج منطقة حالة، فيسمع قارئ الشاشة العدد الجديد.
- يمكن الوصول إلى حقل البحث وزر «عرض المزيد» (`aria-expanded`) بمفتاح <kbd>Tab</kbd>. يحبس الدرج ومربع الحوار التركيز ويعيدانه إلى الزر. النص 4.5:1 ولكل عنصر تحكم تباينه.

## الاختلافات عن DGA [#deviations-from-dga]

- في Figma زر المشغّل فقط (`Open` و`Result` و`Show Results` ومواضع `Left` و`Center` و`Right`). اللوحة والوسوم والدرج ومربع الحوار مركّبة هنا من مكوّنات DGA، ومواضع اليسار واليمين هي `start` و`end` المنطقيان فتنعكس في RTL.
- مجموعات البحث وعرض المزيد والتاريخ والتقييم والمخصص مأخوذة من الأجزاء الفرعية في Figma (`_Filtration list` و`_Multi Select Checkbox Filter` و`_Text Range`) ومن Search Box وDate Picker وRating في DGA؛ وكلها اختيارية.
