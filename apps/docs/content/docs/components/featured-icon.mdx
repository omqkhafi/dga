## Usage

```tsx title="page.tsx"
import { CheckmarkCircle02Icon } from "@hugeicons/core-free-icons";
import { HugeiconsIcon } from "@hugeicons/react";
import { FeaturedIcon } from "@/components/dga/featured-icon";

<FeaturedIcon variant="success">
  <HugeiconsIcon icon={CheckmarkCircle02Icon} />
</FeaturedIcon>
```

A featured icon draws attention to a card, an empty state or a dialog, and hints at its meaning with colour.

## Anatomy

- **Root**: the tinted square or circle.
- **Icon**: any Hugeicons icon, sized to the container (16 to 28px).

## Examples

### Appearance and colour

`light` is a tint, `hard` a solid fill and `outlined` a ring, in `brand`, `neutral`, `success`, `error`, `warning` and `info`. Sizes `sm` 32px to `xl` 56px; `circle` makes it round.

## RTL

Place it at the start of a card; directional icons need `rtl:-scale-x-100`.

<DirectionCompare name="featured-icon" title="Featured icon" />

## Accessibility

- Decorative by default (`aria-hidden`), because the text next to it carries the meaning.
- If the icon alone carries meaning, pass `role="img"` and an `aria-label`.
- Icons are checked at 3:1 against their fill and the page surface.
