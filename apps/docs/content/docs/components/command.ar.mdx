## الاستخدام [#usage]

```tsx title="page.tsx"
import { File01Icon } from "@hugeicons/core-free-icons";
import { CommandDialog } from "@/components/dga/command";

const groups = [
  {
    label: "الخدمات",
    items: [
      {
        value: "renew",
        label: "تجديد رخصة",
        icon: File01Icon,
        shortcut: "⌘R",
        onSelect: () => router.push("/renew"),
      },
    ],
  },
];

export function Palette() {
  const [open, setOpen] = useState(false);
  useEffect(() => {
    const onKey = (event: KeyboardEvent) => {
      if ((event.metaKey || event.ctrlKey) && event.key === "k") {
        event.preventDefault();
        setOpen((value) => !value);
      }
    };
    document.addEventListener("keydown", onKey);
    return () => document.removeEventListener("keydown", onKey);
  }, []);
  return (
    <CommandDialog
      items={groups}
      open={open}
      onOpenChange={setOpen}
      title="قائمة الأوامر"
      placeholder="اكتب أمرًا أو ابحث…"
      emptyText="لا توجد أوامر مطابقة."
    />
  );
}
```

Command **ينفّذ إجراءات** ولا يحفظ قيمة. وللحقل الذي يحفظ اختيارًا في نموذج استخدم [Combobox](/docs/components/combobox). يتشاركان البحث نفسه (لا يفرّق بين حالات الأحرف ويراعي العربية) وشكلًا متقاربًا للعناصر، لكن عنصر Command له أيقونة واختصار و`onSelect`، وقائمته مفتوحة دائمًا. يضع `Command` المربع والقائمة في الصفحة، ويضعهما `CommandDialog` داخل [Dialog](/docs/components/dialog). ولا يربط المكوّن المفتاحين <kbd>Ctrl</kbd> أو <kbd>⌘</kbd> مع <kbd>K</kbd>: يقرر تطبيقك أي المفاتيح تفتحه، كما في المثال.

أيقونة البحث والنص على اليمين، والاختصارات على اليسار وتبقى من اليسار إلى اليمين، وشريط التظليل على اليمين.

## البنية [#anatomy]

- **مربع البحث**: شكل [Search Box](/docs/components/search-box) مع أيقونة البحث في جهة البداية.
- **النتائج**: سطح [Menu](/docs/components/menu) بحد 1px وزوايا radius-md.
- **المجموعة** و**العنوان**: عناوين للإجراءات المتقاربة.
- **العنصر**: بارتفاع 40px، وأيقونة اختيارية، والنص، واختصار اختياري في جهة النهاية. ويبقى الاختصار من اليسار إلى اليمين.
- **نص الفراغ**: يظهر حين لا يطابق شيء.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| الكتابة | تصفّي الإجراءات وتظلّل أول مطابق. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> | ينقلان التظليل. |
| <kbd>Enter</kbd> | ينفّذ الإجراء المظلَّل. |
| <kbd>Esc</kbd> | في الحوار يغلقه ويعيد التركيز إلى الزر الذي فتحه. |

- مربع البحث `combobox` يتحكم في `listbox`؛ ويُكشف الإجراء المظلَّل بـ `aria-activedescendant` ويبقى التركيز في المربع. سمِّ المربع بـ `inputLabel`.
- يُعلَن عدد النتائج بهدوء كلما تغيّر (`countLabel`).
- للحوار عنوان ووصف لقارئ الشاشة (`title` و`description`)، ويحبس التركيز ويعطّل الصفحة خلفه.
- للإجراء المظلَّل شريط بعرض 2px إضافة إلى التظليل. النص بتباين 4.5:1 والاختصار 4.5:1 على التظليل، في الفاتح والداكن.

## الاشتقاق [#derivation]

- غير موجود في DGA. القائمة وعناصرها من [Menu](/docs/components/menu)، والحقل من [Search Box](/docs/components/search-box)، والحوار من [Dialog](/docs/components/dialog).
- أبقيناه منفصلًا عن Combobox لأنه يؤدي عملًا مختلفًا (تنفيذ إجراءات لا اختيار قيمة) وليس له قيمة في نموذج. ويشارك Combobox دالة البحث.
- لا ألوان جديدة ولا رموز جديدة.

## الاختلافات عن DGA [#deviations-from-dga]

- لا توجد قائمة أوامر في DGA ليُختلف عنها. هذه قائمة بما خالفنا فيه المكوّنات المبني عليها.
- للإجراء المظلَّل شريط إضافة إلى تظليل Menu عند التمرير، لأن التركيز يبقى في مربع البحث والتظليل وحده بتباين 1.1:1.
