## Usage

```tsx title="page.tsx"
import { Button } from "@/components/dga/button";
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/dga/popover";

export function RequestDetails() {
  return (
    <Popover>
      <PopoverTrigger render={<Button variant="outline" />}>Request details</PopoverTrigger>
      <PopoverContent showCloseButton>
        <PopoverHeader>
          <PopoverTitle>Request 24810</PopoverTitle>
          <PopoverDescription>Submitted on 8 November.</PopoverDescription>
        </PopoverHeader>
      </PopoverContent>
    </Popover>
  );
}
```

Use a Popover for extra detail or a short form that belongs to one control: a date range, a rename field, a filter. It stays open until the person closes it, so it can hold interactive content. For a hint that only names something, use a [Tooltip](/docs/components/tooltip). For a list of actions, use a [Menu](/docs/components/menu). For anything that needs a decision before the page can go on, use a [Dialog](/docs/components/dialog).

The panel aligns to the centre of the trigger by default; with `align="start"` it lines up with the right edge in Arabic. `start` and `end` swap, and the beak follows. Text, the close button and the footer follow the page direction.

## Anatomy

- **Trigger**: the button that opens it. It has `aria-expanded` and `aria-haspopup="dialog"`.
- **Panel**: `background-menu`, a 1px border, radius-md, `shadow-2xl`, 16px padding, 288px wide, never wider than the screen.
- **Header**: a title (`text-display`, semibold) and a description (`text-primary-paragraph`). The panel is named by the title and described by the description.
- **Beak** (optional): the 14px point toward the trigger, the same as the Tooltip. Turn it on with `showArrow`.
- **Close button** (optional): a 32px icon button in the corner, with `showCloseButton`.
- **Footer**: actions aligned to the end. Use PopoverClose to close the panel from a button.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | On the trigger, opens the panel and moves focus into it. |
| <kbd>Tab</kbd> | Moves through the controls inside the panel, then on to the rest of the page. |
| <kbd>Escape</kbd> | Closes the panel and returns focus to the trigger. |

- Built on Base UI Popover: the panel is `role="dialog"`, named by PopoverTitle and described by PopoverDescription. It is not modal, so the page stays reachable and focus is not trapped.
- Clicking outside closes it, and so does the close button. The close button has an accessible name (`closeLabel`).
- Text is 4.5:1 and icons and focus rings 3:1 or better on the panel, in light and dark.
- It fades and scales in; with reduced motion it appears without animation.

## Derivation from DGA

DGA has no popover, so this is not a DGA component and has no DGA specification. Its look is the DGA Menu surface (`background-menu`, border, radius-md, `shadow-2xl`) with the Tooltip beak and the Dialog close button. No colour is new: every one comes from an existing DGA token.
