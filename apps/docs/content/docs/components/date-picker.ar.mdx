## الاستخدام [#usage]

```tsx title="page.tsx"
import { useState } from "react";
import { DatePicker } from "@/components/dga/date-picker";
import { Field, FieldDescription, FieldLabel } from "@/components/dga/field";

export function AppointmentDate() {
  const [date, setDate] = useState<string | null>(null);
  return (
    <Field>
      <FieldLabel>تاريخ الموعد</FieldLabel>
      <DatePicker value={date} onValueChange={setDate} min="2026-11-09" />
      <FieldDescription>اكتب التاريخ أو اخترْه من التقويم.</FieldDescription>
    </Field>
  );
}
```

التاريخ دائمًا نص ISO ميلادي مثل `"2026-11-08"`، أيًّا كان التقويم المعروض، فلا تتأثر القيمة بالمنطقة الزمنية. استخدم `Calendar` وحده لتقويم ظاهر دائمًا، و`mode="range"` لبداية ونهاية (`{ start, end }`).

مرّر كل نص ظاهر في `labels` و`placeholder`؛ وفي الصفحات العربية مرّر أيضًا `numerals="arab"` للأرقام الهندية العربية. تتبع أسماء الأشهر والأيام اتجاه الصفحة (العربية حين تكون من اليمين إلى اليسار) أو `locale`.

تبدأ الشبكة بأول أيام الأسبوع على اليمين، وتنعكس أسهم الشهر، ويتبادل اليمين واليسار. أسماء الأشهر والأيام بالعربية.

## البنية [#anatomy]

- **الحقل**: Input وفي نهايته زر التقويم. اكتب `YYYY-MM-DD` في التقويم المعروض (تصلح أي أرقام)؛ يُتحقق منه عند مغادرة الحقل أو الضغط على Enter. للنطاق حقل بداية وحقل نهاية.
- **النافذة المنبثقة**: تُفتح بالزر وتُغلق بـ <kbd>Esc</kbd> ويعود التركيز إلى الزر. تعبئتها تعبئة الحقل بزوايا `radius-md` وظل كبير.
- **مبدّل التقويم**: ميلادي أو هجري (`calendars` يقصره على واحد).
- **الترويسة**: الشهر السابق، والشهر والسنة، والشهر التالي. يعرض `months={2}` شهرين جنبًا إلى جنب.
- **خلية التاريخ**: بحجم 56px وفيها دائرة بحجم 48px. لليوم الحالي حلقة، وللمختار التعبئة الأساسية، وللأيام بين طرفي النطاق شريط باهت. يعرض `secondaryDate` يوم التقويم الآخر.
- **الخيارات السريعة** (`quickOptions`) و**إلغاء وتطبيق** (`confirm`).

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Left</kbd> / <kbd>Right</kbd> | اليوم السابق أو التالي. يتبادلان في الصفحات العربية. |
| <kbd>Up</kbd> / <kbd>Down</kbd> | الأسبوع السابق أو التالي. |
| <kbd>Home</kbd> / <kbd>End</kbd> | أول يوم في الأسبوع أو آخره. |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | الشهر السابق أو التالي. |
| <kbd>Shift</kbd> + <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | السنة السابقة أو التالية. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | يختار اليوم المركَّز. |
| <kbd>Esc</kbd> | يغلق النافذة المنبثقة. |

- كل شهر `grid` يسميه عنوانه، بعناوين أعمدة و`aria-selected` على الأيام المختارة و`aria-current="date"` على اليوم. كل يوم زر اسمه تاريخه الكامل، مثل «الأحد ٨ نوفمبر ٢٠٢٦» في التقويم المعروض.
- يوم واحد في ترتيب Tab وينتقل بمفاتيح الأسهم. لليوم المعطل `aria-disabled` ويبقى قابلًا للوصول.
- عنوان الشهر منطقة حية، فيسمع قارئ الشاشة الشهر الجديد.
- النص 4.5:1 والحلقات والتركيز 3:1 في الفاتح والداكن، في كل حالات الخلية.

## الاختلافات عن DGA [#deviations-from-dga]

- يرسم Figma تقويمًا ميلاديًا فقط. أُضيف التقويم الهجري والمبدّل.
- لم تُبنَ «قائمة السنة» في Figma: يغيّر Shift مع Page Up وPage Down السنة.
- يمكن اختيار أيام الشهر السابق والتالي في شهر واحد، وتُترك فارغة في شهرين.
