## الاستخدام [#usage]

```tsx title="page.tsx"
import { Progress } from "@/components/dga/progress";

export function Upload({ percent }: { percent: number }) {
  return <Progress value={percent} label="جارٍ الرفع" helperText="أبقِ هذه الصفحة مفتوحة." />;
}
```

استخدم التقدم لمهمة معلومة المدة، كالرفع أو نموذج من أجزاء عدة. وحين لا يُعرف المدى مرّر `value={null}`. وللانتظار ثانية أو ثانيتين استخدم [Spinner](/docs/components/spinner). ولبيان موضع الشخص في تسلسل صفحات استخدم [Stepper](/docs/components/stepper).

يمتلئ الشريط من اليمين وتدور الحلقة في الاتجاه المعاكس.

## البنية [#anatomy]

- **الشريط**: تسمية ونسبة مئوية، ومسار وتعبئة، وسطر مساعدة. ارتفاع الشريط 8 أو 12 أو 16px (قيمة `size` هي `sm` أو `md` أو `lg`). وقيمة `tone` إما `primary` أو `neutral`.
- **الحلقة** (`ProgressCircle`): بحجم 64 أو 80 أو 120 أو 160 أو 200px، وفي وسطها النسبة وتسمية قصيرة (تُخفى تحت 120px).
- **الحالة**: يضيف `success` و`error` أيقونة مدورة واللون المناسب؛ ويقول نص المساعدة ما حدث.

## إمكانية الوصول [#accessibility]

- مبني على Base UI Progress: `role="progressbar"` مع `aria-valuenow` و`aria-valuemin` و`aria-valuemax`، مسمّى بالتسمية. ولا يحمل الشريط غير المحدد `aria-valuenow`.
- التقدم غير تفاعلي ولا يأخذ تركيز لوحة المفاتيح. وأعلن نهاية المهمة في منطقة حية أو في [Notification](/docs/components/notification)، فالشريط لا يعلنها.
- التعبئة بنسبة 3:1 على المسار، والتسمية والقيمة ونص المساعدة 4.5:1، فاتحًا وداكنًا. والنجاح والخطأ ليسا بلون وحده: فيضيفان أيقونة ونص مساعدة.
- تتوقف الحركة حين يفضّل الشخص تقليلها.
