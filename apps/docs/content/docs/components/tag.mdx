## Usage

```tsx title="page.tsx"
import { StatusTag, Tag } from "@/components/dga/tag";

<Tag variant="info">Technical</Tag>
<StatusTag variant="success">Complete</StatusTag>
```

Tags label content by category or show the filters a user has picked. Status tags show the state of an item, task or request.

The dot, icon and close button sit on the logical start and end sides.

## Anatomy

- **Tag**: a `<span>` with optional icon and close button.
- **StatusTag**: a `<span>` with a coloured dot and the label.
- **Close button** (optional): a real `<button>` with a 24px hit area.

## Examples

### Removable

Pass `onDismiss` to add a close button. Give it a specific name with `dismissLabel`, such as "Remove Riyadh", and move focus somewhere sensible after the tag is removed.

<Preview compact name="tag-dismiss" title="Removable" />

### Status Tag

`subtle` (default) sits on a tint, `inverted` on a solid fill and `ghost` has no fill. All three start with a coloured dot.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the close button of a removable tag. |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Removes the tag. |

- Tags are `<span>`s and are read as text. Put the meaning in the label; the colour and dot are extras (WCAG 1.4.1).
- The close button has its own name and a 24px hit area (WCAG 2.5.8).
- Use [Button](/docs/components/button) with `aria-pressed` for tags the user can toggle.
