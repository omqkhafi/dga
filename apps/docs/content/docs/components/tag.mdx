Tags label content by category or show the filters a user has picked. Status tags show the state of an item, task or request.

## Usage

```tsx title="page.tsx"
import { StatusTag, Tag } from "@/components/ui/tag";

<Tag variant="info">تقنية</Tag>
<StatusTag variant="success">مكتمل</StatusTag>
```

## Removable

Pass `onDismiss` to add a close button. Give it a specific name with `dismissLabel`, such as "إزالة الرياض", so screen-reader users know which filter it removes. Move focus to a sensible place after the tag is removed (for example the next tag or the filter field).

## Status Tag

`subtle` (default) sits on a tint, `inverted` on a solid fill and `ghost` has no fill. All three start with a coloured dot.

## Accessibility

- Tags are `<span>`s and are read as text. Put the meaning in the label; the colour and dot are extras (WCAG 1.4.1).
- The close button is a real `<button>` with its own name and a 24px hit area (WCAG 2.5.8).
- Use [Button](/docs/components/button) with `aria-pressed` for tags the user can toggle on and off.
