## الاستخدام [#usage]

```tsx title="page.tsx"
import { Item, ItemActions, ItemContent, ItemDescription, ItemMedia, ItemTitle } from "@/components/dga/item";
import { Button } from "@/components/dga/button";

export function Request() {
  return (
    <Item variant="outline">
      <ItemMedia variant="icon">{/* أيقونة */}</ItemMedia>
      <ItemContent>
        <ItemTitle>تجديد جواز السفر</ItemTitle>
        <ItemDescription>قُدّم في ٨ نوفمبر.</ItemDescription>
      </ItemContent>
      <ItemActions>
        <Button variant="outline" size="sm">عرض</Button>
      </ItemActions>
    </Item>
  );
}
```

استخدم Item لصف فيه أكثر من سطر نص: له متسع للوسائط وسطرين من النص والإجراءات. وللقائمة النقطية أو المرقمة العادية استخدم [List](/docs/components/list)، ولكتلة محتوى استخدم [Card](/docs/components/card)، وللصفوف ذات الأعمدة استخدم [Table](/docs/components/table).

تقع الوسائط في جهة البداية والإجراءات في جهة النهاية، فينعكس الصف. ويتبع النص اتجاه الصفحة.

## البنية [#anatomy]

- **Item**: الصف. الأنماط `default` (بلا تعبئة) و`outline` (حد 1px بلون `border-neutral-primary`) و`muted` (`background-neutral-50`). والحجمان `default` (حشوة 16px) و`sm`.
- **الوسائط**: `default` لأي محتوى مثل Avatar، و`icon` لأيقونة داخل إطار بقياس 40px، و`image` لصورة مقصوصة بقياس 40px.
- **المحتوى**: العنوان (`text-md` شبه عريض بلون `text-display`) والوصف (`text-sm` بلون `text-primary-paragraph`، سطران على الأكثر).
- **الإجراءات**: أزرار أو شارة في النهاية. أما **الترويسة** و**التذييل** فسطران بعرض كامل فوق الصف وتحته.
- **المجموعة** و**الفاصل**: تكدّس ItemGroup الصفوف، وItemSeparator هو Divider من DGA بينها.

## إمكانية الوصول [#accessibility]

- ليس لـ Item دور. والصف الذي هو رابط يحتفظ بدلالة الرابط، ويكون الصف كله محطة Tab واحدة، فلا تضع أزرارًا متداخلة في صف رابط.
- للقائمة استخدم `render={<ul />}` على ItemGroup و`render={<li />}` على كل Item.
- يظهر التركيز بإطار 2px بلون `border-black`، بنسبة 3:1 أو أفضل على كل سطح.
- النص 4.5:1 والأيقونات 3:1 على الصفحة وعلى لون التمرير وعلى التعبئة الخافتة، فاتحًا وداكنًا.
