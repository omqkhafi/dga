## الاستخدام [#usage]

```tsx title="page.tsx"
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuSeparator,
  ContextMenuTrigger,
} from "@/components/dga/context-menu";

export function RequestRow() {
  return (
    <ContextMenu>
      <ContextMenuTrigger aria-label="الطلب ٢٤٨١٠. انقر بالزر الأيمن للإجراءات.">
        الطلب ٢٤٨١٠
      </ContextMenuTrigger>
      <ContextMenuContent>
        <ContextMenuItem>تعديل الطلب</ContextMenuItem>
        <ContextMenuSeparator />
        <ContextMenuItem>سحب الطلب</ContextMenuItem>
      </ContextMenuContent>
    </ContextMenu>
  );
}
```

قائمة السياق اختصار لمن يعرف أن يبحث عنه. **يجب أن يمكن الوصول إلى كل إجراء فيها بطريقة أخرى**، كزر [Menu](/docs/components/menu) ظاهر على الصف نفسه، لأن أغلب الناس لا ينقرون بالزر الأيمن ومستخدمو اللمس عليهم الضغط مطولًا. استخدمها على الصفوف والبطاقات والملفات ولوحات الرسم. قائمتها هي Menu في DGA فتعمل العناصر بالطريقة نفسها.

تفتح القائمة عند المؤشر ويتبع نصها اتجاه الصفحة. وتفتح القائمة الفرعية في جهة النهاية أي على اليسار بالعربية، ويُعكس سهمها. ويتبادل اليمين واليسار: فاليسار يفتح قائمة فرعية بالعربية. وتبقى الاختصارات من اليسار إلى اليمين.

## البنية [#anatomy]

- **منطقة الفتح**: أي منطقة. يمكن تركيزها (`tabIndex=0`) فيفتح مستخدم لوحة المفاتيح القائمة. سمِّها بـ `aria-label` إن كان محتواها لا يدل على وجود قائمة.
- **القائمة** (`role="menu"`): `background-menu` وحد بسمك 1px وانحناء radius-md و`shadow-2xl`. تفتح عند المؤشر وتبقى بعيدة عن حواف الشاشة.
- **العناصر**: ContextMenuItem (بارتفاع 40px وأيقونة وتسمية واختصار) وContextMenuCheckboxItem وContextMenuRadioItem.
- **المجموعات**: ContextMenuGroup مع ContextMenuLabel، وContextMenuSeparator.
- **القائمة الفرعية**: ContextMenuSub مع ContextMenuSubTrigger وContextMenuSubContent.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Shift</kbd> + <kbd>F10</kbd> أو مفتاح القائمة | على المنطقة المركَّزة يفتح القائمة. |
| الضغط المطول | على شاشة اللمس يفتح القائمة. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> | ينتقل بين العناصر. |
| <kbd>Home</kbd> / <kbd>End</kbd> | ينتقل إلى العنصر الأول أو الأخير. |
| <kbd>ArrowRight</kbd> | يفتح قائمة فرعية (ArrowLeft بالعربية)؛ ويغلقها السهم المعاكس. |
| <kbd>Enter</kbd> أو <kbd>Space</kbd> | يختار العنصر المركَّز. |
| <kbd>Escape</kbd> | يغلق القائمة ويعيد التركيز إلى المنطقة. |

- مبنية على Base UI ContextMenu: `role="menu"` وعناصر `menuitem` و`menuitemcheckbox` و`menuitemradio` وتركيز متنقل، ويعود التركيز إلى المنطقة عند الإغلاق.
- لا تُستبدل قائمة المتصفح إلا داخل المنطقة. وفي بقية الصفحة تعمل القائمة المعتادة.
- النص بنسبة 4.5:1 والأيقونات والحلقات 3:1 أو أفضل في كل حالة، فاتحًا وداكنًا. ويبقى العنصر المعطّل في ترتيب مفاتيح الأسهم لكن لا يمكن اختياره.

## الاشتقاق من DGA [#derivation-from-dga]

لا تعرّف DGA قائمة سياق، فهذا ليس مكوّنًا من DGA. القائمة والعناصر والقوائم الفرعية هي Menu في DGA، والعناصر هي مكوّنات Menu نفسها. والإضافة الوحيدة هي حلقة تركيز منطقة الفتح. ولا لون جديد فيه.
