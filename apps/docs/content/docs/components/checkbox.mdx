## Usage

```tsx title="page.tsx"
import { Checkbox } from "@/components/dga/checkbox";
import { Field, FieldContent, FieldLabel } from "@/components/dga/field";

export function ConsentField() {
  return (
    <Field orientation="horizontal" name="consent">
      <Checkbox required />
      <FieldContent>
        <FieldLabel>I confirm the information is correct</FieldLabel>
      </FieldContent>
    </Field>
  );
}
```

Use a Checkbox when someone can choose none, one or several options, or confirm something before submitting. The choice is applied when the form is submitted; for a setting that takes effect at once use [Switch](/docs/components/switch). For exactly one of several options use [Radio](/docs/components/radio).

## Anatomy

- **Box** (`<span role="checkbox">` and a hidden `<input>`): the border and fill.
- **Mark**: a check, or a dash when indeterminate.
- **Label**, **helper text** and **error**: from [Field](/docs/components/field), beside the box.

## RTL

The box is on the right (start) of its label and the helper text lines up under the label. The check mark is not directional, so it is not flipped.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the checkbox. |
| <kbd>Space</kbd> | Checks or unchecks it. |

- The `checkbox` role with `aria-checked` (`true`, `false` or `mixed`), and a hidden native input for forms.
- The label is from [Field](/docs/components/field); clicking it toggles the box.
- The unchecked border is 3:1 or better on every surface; the checked fill and the mark are 3:1 against the surface and against each other (WCAG 1.4.11).
- Focus is a 2px outline 2px outside the box. Read-only keeps a 3:1 border.
- Errors show an icon and text with `aria-invalid`, not a colour change alone.

## Deviations from DGA

- In dark mode the checked fill stays green-600 on hover and press, because Figma's lighter greens give the white mark 1.4–2.1:1.
- The neutral check mark flips with the fill (new token `control-icon-neutral`).
- Read-only has a 3:1 border (Figma: 1.5:1).
