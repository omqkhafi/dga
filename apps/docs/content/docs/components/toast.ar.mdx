## الاستخدام [#usage]

```tsx title="page.tsx"
import { Button } from "@/components/dga/button";
import { Toaster, toast } from "@/components/dga/toast";

// Once, at the root of the app (for example in layout.tsx).
export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <Toaster closeLabel="إغلاق" regionLabel="الإشعارات" />
    </>
  );
}

export function SubmitButton() {
  return (
    <Button
      onClick={() =>
        toast.add({
          type: "success",
          title: "تم إرسال الطلب",
          description: "رقمك المرجعي ٢٤٨١٠.",
        })
      }
    >
      إرسال
    </Button>
  );
}
```

استخدم Toast لتأكيد أمر حدث للتو ولا يحتاج ردًا: أُرسل طلب أو حُفظت مسودة. ولا تستخدمه لخطأ يعيق الشخص (اعرضه بجانب الحقل أو في [Inline Alert](/docs/components/inline-alert)) ولا لشيء يجب أن يتصرف حياله قبل أن يختفي. ضع `Toaster` واحدًا في الجذر واستدعِ `toast.add({ title, description, type })` من أي مكان، حتى خارج React. قيمة `type` هي `neutral` أو `info` أو `success` أو `warning` أو `error`. ويزول الإشعار بعد 6 ثوانٍ؛ ومرّر `timeout: 0` ليبقى حتى يُغلق، واستخدمه للأخطاء التي يحتاج الناس إلى قراءتها. أبقِ الرسالة في جملة قصيرة؛ ويتيح زر `actionProps` إجراءً سريعًا واحدًا (مثل «تراجع»).

تظهر الإشعارات عند نهاية أسفل الشاشة: أسفل اليمين بالإنجليزية وأسفل اليسار بالعربية. والشريط في جهة البداية، ويزيلها السحب نحو الحافة التي جاءت منها.

## البنية [#anatomy]

- **Toaster** (`role="region"` ومنطقة حية): القائمة عند نهاية أسفل الشاشة. تحمل ثلاثة إشعارات على الأكثر.
- **الإشعار**: بعرض 484px (وعرض كامل على الجوال)، وانحناء radius-md و`shadow-3xl`، على `background-notification-white`.
- **الشريط**: 8px في جهة البداية، بلون النوع (الدرجة 400).
- **الأيقونة** و**العنوان** و**الوصف**، و**إجراء** اختياري و**زر إغلاق**.

### المهلة والأولوية والإجراءات [#timeout-priority-and-actions]

يُغلق الإشعار تلقائيًا بعد ست ثوانٍ. مرّر `timeout: 0` إلى `toast.add` ليبقى حتى يغلقه الشخص، و`actionProps` لإضافة زر. التحذيرات والأخطاء تستخدم `priority: "high"` فيعلنها قارئ الشاشة فورًا، وغيرها ينتظر دوره. يظهر ثلاثة إشعارات فقط في وقت واحد (`limit` على Toaster)، ويصطف الباقي خلفها.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>F6</kbd> | ينقل التركيز إلى منطقة الإشعارات (عند وجود إشعارات). ويعيده Escape أو النقر في مكان آخر. |
| <kbd>Tab</kbd> | ينتقل بين زرَّي الإجراء والإغلاق في الإشعارات. |
| <kbd>Enter</kbd> | يضغط زر الإجراء أو الإغلاق المركَّز. |
| <kbd>Escape</kbd> | يغلق الإشعار المركَّز. |

- مبنية على Base UI Toast. والإطار منطقة حية: تُعلَن الإشعارات الجديدة دون تحريك التركيز (`polite` أو `assertive` عند `priority: "high"`). اكتب جملًا قصيرة كاملة.
- لا يزول الإشعار ما دام المؤشر فوقه أو التركيز داخله، ويعاد المؤقت بعد ذلك (WCAG 2.2.1). واستخدم `timeout: 0` لما قد يحتاج الناس وقتًا أطول لقراءته.
- يظهر النوع من الأيقونة والعنوان إضافة إلى الشريط، لا من اللون وحده. والنص بنسبة 4.5:1 والأيقونات 3:1 أو أفضل، فاتحًا وداكنًا. ولزر الإغلاق اسم (`closeLabel`).
- ومع تقليل الحركة يظهر الإشعار ويزول دون انزلاق.

## الاختلافات عن DGA [#deviations-from-dga]

- الشريط المحايد هو `border-neutral-primary`: بينما ترسمه DGA أبيض فلا يُرى على البطاقة البيضاء. والشريط منطقي (جهة البداية).
- لا تحدد DGA أي توقيت أو إعلان. وتتوقف الإشعارات مؤقتًا أثناء التمرير أو التركيز، ويمكن سحبها لإزالتها، وتُعلَن، ويقع Toaster عند نهاية أسفل الشاشة.
