## Usage

```tsx title="page.tsx"
import { Field, FieldContent, FieldLabel } from "@/components/dga/field";
import { Switch } from "@/components/dga/switch";

export function UpdatesField() {
  return (
    <Field orientation="horizontal" className="items-center justify-between">
      <FieldContent>
        <FieldLabel>Send me updates about this request</FieldLabel>
      </FieldContent>
      <Switch name="updates" defaultChecked />
    </Field>
  );
}
```

Use a Switch for a setting that takes effect the moment it is flipped: notifications, a feature on or off. If the choice is only applied when a form is submitted, use [Checkbox](/docs/components/checkbox). Label what the switch does, not its state: "Request updates", not "On".

## Anatomy

- **Track** (`<span role="switch">` and a hidden `<input>`): 48 by 24px.
- **Thumb**: the white circle that slides; it holds the check icon when `icon` is set.
- **Label**, **helper text** and **error**: from [Field](/docs/components/field). Put the switch after FieldContent to trail it.

## RTL

The thumb moves along the logical axis: it starts on the right and slides left when on, the way the track reads. Nothing is flipped by hand; a trailing switch sits on the left.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the switch. |
| <kbd>Space</kbd> | Turns it on or off. |

- The `switch` role with `aria-checked`, and a hidden native input for forms.
- The label is from [Field](/docs/components/field); clicking it flips the switch.
- The off track and its white thumb, and the on track and thumb, are 3:1 or better in light and dark (WCAG 1.4.11). State is also shown by the thumb position, not colour alone.
- Focus is a 2px outline 2px outside the track. An error adds a 2px error outline and a message with an icon.
- Respects reduced motion: the thumb moves without animation.

## Deviations from DGA

- The off track is `control-border` (4.8:1) instead of #ccc (1.6:1), with a white thumb (new token `control-thumb`).
- Hover and press on the on track keep green-600 in dark mode (see [Checkbox](/docs/components/checkbox)).
