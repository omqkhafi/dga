## Usage

```tsx title="page.tsx"
import { TableOfContents } from "@/components/dga/table-of-contents";

const sections = [
  { id: "overview", title: "Overview" },
  { id: "eligibility", title: "Eligibility" },
  { id: "citizens", title: "Citizens", level: 2 },
  { id: "documents", title: "Documents" },
];

export function PageOutline() {
  return <TableOfContents title="On this page" items={sections} />;
}
```

Use it on a long page with several sections, in a side column that stays in view. Each `id` must match an element on the page (usually a heading), and those elements need `scroll-margin-top` if the header is sticky. It follows the scroll position by itself; pass `activeId` to control it. For moving between pages use a [Tabs](/docs/components/tabs) or a [Breadcrumb](/docs/components/breadcrumb).

## Anatomy

- **Table of Contents** (`nav`): at most 228px wide. The title is Text sm Medium in `text-primary-paragraph`.
- **Link**: 32px high, 16px of padding at the start and 8px at the end, radius xs. Levels 2 and 3 (h3 and h4) are indented.
- **Current section**: Semibold `text-default`, with `aria-current="location"`.
- **Hover and pressed**: the neutral button fills. **Focus**: a 2px outline.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves to the list, then out of it. |
| <kbd>ArrowDown</kbd> | Moves to the next link. |
| <kbd>ArrowUp</kbd> | Moves to the previous link. |
| <kbd>Home</kbd> | Moves to the first link. |
| <kbd>End</kbd> | Moves to the last link. |
| <kbd>Enter</kbd> | Goes to the section. |

- A `nav` landmark named by its title, with links to in-page anchors. The current one has `aria-current="location"`; the Semibold weight is a second cue besides the colour.
- Every link is 4.5:1 in light and dark, on hover and pressed too.
