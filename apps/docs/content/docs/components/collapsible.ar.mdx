## الاستخدام [#usage]

```tsx title="page.tsx"
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/dga/collapsible";

export function RequiredDocuments() {
  return (
    <Collapsible className="flex flex-col gap-3">
      <CollapsibleTrigger showChevron>المستندات المطلوبة</CollapsibleTrigger>
      <CollapsibleContent>الهوية الوطنية وصورة حديثة وجواز السفر السابق.</CollapsibleContent>
    </Collapsible>
  );
}
```

استخدم Collapsible لكتلة واحدة من التفاصيل لا يحتاجها معظم الناس: وصف أطول أو خيارات إضافية أو قائمة «عرض المزيد». ولعدة لوحات يغلق فتحُ إحداها الأخرى استخدم [Accordion](/docs/components/accordion). ولبطاقة تُفتح تفاصيلها استخدم القسم القابل للتوسيع في [Card](/docs/components/card)، وهو هذا المكوّن داخل بطاقة.

## البنية [#anatomy]

- **الزر**: زر له `aria-expanded` و`aria-controls`. لونه `text-display` وخطه عريض بحجم 18px. فعّل السهم بـ `showChevron` أو اعرض زرك الخاص بـ `render`.
- **السهم** (اختياري): سهم بعرض 20px بلون `icon-default` يدور عند فتح اللوحة.
- **المحتوى**: اللوحة بلون `text-primary-paragraph`. يتحرك ارتفاعها خلال أقل من ربع ثانية.

لا نمط للجذر، فأعطه التخطيط الذي تحتاجه (`flex flex-col gap-3` أعلاه).

## القسم القابل للتوسيع في البطاقة [#card-expandable]

المكوّنات `CardExpandable` و`CardExpandableTrigger` و`CardExpandablePanel` في البطاقة هي هذا المكوّن وحوله سطح البطاقة. تثبيت البطاقة يثبّت Collapsible معها، فيوجد تنفيذ واحد لسلوك الفتح والإغلاق. ولم يتغير شكل البطاقة.

## RTL [#rtl]

يتبع السهم والنص اتجاه الصفحة. يشير السهم إلى الأسفل في الاتجاهين، فلا شيء ينعكس.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Enter</kbd> أو <kbd>Space</kbd> | على الزر، يفتح اللوحة أو يغلقها. |
| <kbd>Tab</kbd> | ينتقل إلى الزر ثم إلى عناصر التحكم داخل اللوحة المفتوحة. |

- مبني على Base UI Collapsible: الزر عنصر `button` حقيقي له `aria-expanded` و`aria-controls` يشير إلى اللوحة.
- اللوحة المغلقة مخفية، فلا يمكن الوصول إلى روابطها وأزرارها بلوحة المفاتيح ولا يقرؤها قارئ الشاشة.
- للزر حلقة تركيز بسمك 2px بلون `border-black` بنسبة 3:1 أو أفضل، في الوضعين الفاتح والداكن.
- عند تقليل الحركة تُفتح اللوحة وتُغلق بلا حركة.
