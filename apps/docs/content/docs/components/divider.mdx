## Usage

```tsx title="page.tsx"
import { Divider } from "@/components/ui/divider";

<Divider />
<Divider orientation="vertical" />
```

Built on the [Base UI Separator](https://base-ui.com/react/components/separator).

## Examples

### Colours

`neutral` (default), `primary`, and `alpha-white` and `white` for brand fills.

### Vertical

Set `orientation="vertical"` inside a flex row with a fixed height.

## RTL

A line has no direction. Vertical dividers sit between items in the reading order.

<DirectionCompare name="divider" title="Divider" />

## Accessibility

- Renders `role="separator"` with `aria-orientation`, so screen readers announce the break between sections.
- If the line is purely visual, pass `role="none"`.
