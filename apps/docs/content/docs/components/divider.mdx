A divider separates content into sections so the page is easier to scan. Built on the [Base UI Separator](https://base-ui.com/react/components/separator).

## Accessibility

- Renders `role="separator"` with `aria-orientation`, so screen readers announce the break between sections.
- If the line is purely visual (for example between items that are already grouped), pass `role="none"`.
