## Usage

```tsx title="page.tsx"
import { ScrollArea } from "@/components/dga/scroll-area";

export function Applications({ items }: { items: string[] }) {
  return (
    <ScrollArea label="Applications" className="h-60 w-72 rounded-md border">
      <ul>{items.map((item) => <li key={item}>{item}</li>)}</ul>
    </ScrollArea>
  );
}
```

Use it for a list, a table or a panel that scrolls inside a page that does not, such as a menu, a sidebar section or a log. Give it a height (for a vertical area) or a width (for a horizontal one). If the whole page scrolls, leave the browser's own scrollbar alone.

## Anatomy

- **Viewport**: the scrolling element. It is a focusable region (`tabindex="0"`, `role="region"`) named by `label`, so a keyboard user can focus it and scroll.
- **Scrollbar**: 12px, on the end side of the area. It does not move the content, it sits on top.
- **Thumb**: a rounded bar in `text-secondary-paragraph`, darker when hovered and pressed. There is no track fill.
- **Corner**: with `orientation="both"`, the square where the two bars meet.

### When the scrollbar shows

`visibility="hover"` (default) shows the bar while the pointer is over the area, while it scrolls and while it has keyboard focus. `visibility="always"` keeps it visible, which suits touch screens and anywhere people need to see that there is more.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Focuses the scrollable region. |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Scroll by a line. |
| <kbd>Page Up</kbd> <kbd>Page Down</kbd> | Scroll by a page. |
| <kbd>Home</kbd> <kbd>End</kbd> | Go to the start or the end of a vertical area. |

- The viewport is a `region` with an accessible name from `label`. Always pass one, and translate it on Arabic pages.
- The browser does the scrolling, so touch, wheel and keyboard behave as they do everywhere else.
- The thumb is 3:1 or better against the page in light and dark, and the focus ring is a 2px `border-black` line drawn inside the area.
- The scrollbar fades in and out; with reduced motion it appears without a fade.

## Derivation from DGA

DGA has no scrollbar, so this is not a DGA component and has no DGA specification. The neutral border and background tokens are 1.1:1 to 1.7:1 against the page, so the thumb uses the gray text tokens to meet 3:1. No colour is new.
