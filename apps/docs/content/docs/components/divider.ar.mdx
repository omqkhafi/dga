## الاستخدام [#usage]

```tsx title="page.tsx"
import { Divider } from "@/components/dga/divider";

<Divider />
<Divider orientation="vertical" />
```

مبني على [Base UI Separator](https://base-ui.com/react/components/separator).

الخط بلا اتجاه. تقع الفواصل العمودية بين العناصر وفق ترتيب القراءة.

## أمثلة [#examples]

### الألوان [#colours]

`neutral` (الافتراضي) و`primary`، و`alpha-white` و`white` لتعبئات العلامة.

<Preview compact name="divider-on-color" title="على لون" />

### العمودي [#vertical]

اضبط `orientation="vertical"` داخل صف `flex` بارتفاع ثابت.

<Preview compact name="divider-vertical" title="العمودي" />

## إمكانية الوصول [#accessibility]

- يعرض `role="separator"` مع `aria-orientation`، فتعلن قارئات الشاشة الفاصل بين الأقسام.
- إذا كان الخط بصريًا فقط، مرّر `role="none"`.
