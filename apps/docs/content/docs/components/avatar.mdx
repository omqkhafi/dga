## Usage

```tsx title="page.tsx"
import { Avatar, AvatarGroup } from "@/components/ui/avatar";

<Avatar src="/people/noura.jpg" alt="نورة القحطاني" initials="ن ق" />

<AvatarGroup>
  <Avatar size={32} src="/people/noura.jpg" alt="نورة" />
  <Avatar size={32} initials="+3" aria-label="3 أشخاص آخرون" />
</AvatarGroup>
```

Built on the [Base UI Avatar](https://base-ui.com/react/components/avatar), which shows the fallback while the image loads and if it fails.

## Anatomy

- **Avatar**: the root, with the image or the fallback.
- **Image**: the picture.
- **Fallback**: initials, or a generic user icon.
- **AvatarGroup**: a row of avatars, stacked or spaced.

## Examples

### Sizes and shape

24, 32, 40 (default), 48, 64, 80 and 120px. `square` uses `radius-md`; `bordered` adds a white ring.

### Groups

`AvatarGroup` overlaps its children by 4px with a white ring (`stacked`, the default). Set `stacked={false}` to space them.

## RTL

A group stacks from the start side, so the overlap direction flips in Arabic.

## Accessibility

- Give the image an `alt` with the person's name, unless the name is already shown next to it (then use `alt=""`).
- Initials are read as text. For a "+3" overflow avatar, add an `aria-label` such as "3 more people".
- The fallback icon is hidden from screen readers.
