## الاستخدام [#usage]

```tsx title="layout.tsx"
import { ZoomInAreaIcon, TextFontIcon } from "@hugeicons/core-free-icons";
import { SecondNav } from "@/components/dga/second-nav";

export function PageInfo() {
  return (
    <SecondNav
      aria-label="معلومات الصفحة"
      items={[
        { kind: "weather", label: "غائم 24°" },
        { kind: "date", label: "3-سبتمبر-2024" },
        { kind: "time", label: "2:30 مساءً" },
        { kind: "location", label: "الرياض" },
      ]}
      actions={[
        { label: "تكبير", icon: ZoomInAreaIcon, iconOnly: true, onClick: () => {} },
        { label: "حجم الخط", icon: TextFontIcon, onClick: () => {} },
      ]}
    />
  );
}
```

استخدمه لسياق يخص الموقع كله: الطقس والتاريخ والوقت والموقع، وأدوات مثل التكبير. ضعه في خانة `top` في [Header](/docs/components/header). لكل إدخال `kind` (`weather` أو `date` أو `time` أو `location`) يأتي بأيقونته، أو `icon` من عندك؛ و`iconOnly` يعرض الأيقونة وحدها ويبقى `label` اسمًا للوصول. تبدأ العناصر من حافة البداية، وتكون الإجراءات في النهاية، ويتمرر الشريط من حافة البداية.

## البنية [#anatomy]

- **الشريط**: ارتفاعه 40px، بحشوة 32px، في المنتصف وبعرض 1280px ما لم تستخدم `fullWidth`. **الرمادي** هو neutral-100، و**الأساسي** هو التعبئة الأساسية مع نص على اللون.
- **العنصر** (`items`، الجزء `SecondNavItem`، في DGA: عنصر الشريط الفرعي): أيقونة اختيارية ونص بخط md Regular، بينهما 4px وارتفاعه 24px. له حالة افتراضية وحالة على اللون (على الشريط الأساسي، أو `tone="on-color"` عند استخدامه وحده). الإدخال نص عادي، أو رابط إن كان له `href`، أو زر إن كان له `onClick`.
- **الفاصل**: بين العناصر والإجراءات (`divider`).
- **الإجراءات** (`actions`): العنصر نفسه في نهاية الشريط، بأيقونة ونص أو بأيقونة فقط.
- **الإدخال الحالي** (`current`): غامق ومسطّر، مع `aria-current="page"`. يستخدمه صف الروابط الاختياري.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينتقل إلى الرابط أو الزر التالي. النص العادي لا يستقبل التركيز. |
| <kbd>Enter</kbd> | يتبع الرابط أو يضغط الزر. |

- معلم `nav`: سمِّه بـ `aria-label`. استخدم قائمة روابط لا تبويبات، فلا حاجة لنموذج مفاتيح الأسهم.
- للصفحة الحالية `aria-current="page"` وهي أيضًا غامقة ومسطّرة، فلا تعتمد على اللون.
- للإدخال المركَّز حدّ بسمك 2px: أسود على الرمادي وأبيض على الأساسي. النص 4.5:1 والأيقونات 3:1 في الفاتح والداكن.
- يصل Tab إلى الشريط المتمرر: يظهر كل إدخال حين يأخذ التركيز.

## الاختلافات عن DGA [#deviations-from-dga]

- يرسم Figma مفاتيح ثابتة (`Show Item 2` و`Show Item 3` و`Show Item 4` و`Show Action 2` وما بعدها). هنا `items` و`actions` مصفوفتان.
- أُضيفت أنواع جاهزة للعناصر (`kind`: الطقس والتاريخ والوقت والموقع) وإجراءات بأيقونة فقط (`iconOnly`)، فتأتي الأيقونات وأسماء الوصول مع العنصر.
- أُضيفت الروابط والأزرار والحالة الحالية لصف الروابط الاختياري. لا يرسم DGA روابط هنا.
- يتمرر الشريط بدل أن يلتف.
