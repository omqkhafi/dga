## الاستخدام [#usage]

```tsx title="layout.tsx"
import { SecondNav } from "@/components/dga/second-nav";

export function PageInfo() {
  return (
    <SecondNav
      aria-label="معلومات الصفحة"
      items={[
        { label: "الأحد ٨ نوفمبر" },
        { label: "٢٤° غائم" },
      ]}
      actions={[
        { label: "حجم الخط", onClick: () => {} },
        { label: "المساعدة", href: "/help" },
      ]}
    />
  );
}
```

استخدمه لسياق يخص الموقع كله، أو صفًّا من الروابط إلى الصفحات الشقيقة في قسم. ضعه في خانة `top` في [Header](/docs/components/header). مرّر الأيقونات بـ `icon`.

تبدأ العناصر من اليمين، وتكون الإجراءات على اليسار، ويتمرر الشريط من اليمين.

## البنية [#anatomy]

- **الشريط**: ارتفاعه 40px، بحشوة 32px، في المنتصف وبعرض 1280px ما لم تستخدم `fullWidth`. خط Text md Regular. **الرمادي** هو neutral-100، و**الأساسي** هو التعبئة الأساسية مع نص على اللون.
- **العناصر** (`items`): أيقونة ونص بينهما 4px. الإدخال نص عادي، أو رابط إن كان له `href`، أو زر إن كان له `onClick`.
- **الفاصل**: بين العناصر والإجراءات (`divider`).
- **الإجراءات** (`actions`): في نهاية الشريط.
- **الإدخال الحالي** (`current`): غامق ومسطّر، مع `aria-current="page"`.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | ينتقل إلى الرابط أو الزر التالي. النص العادي لا يستقبل التركيز. |
| <kbd>Enter</kbd> | يتبع الرابط أو يضغط الزر. |

- معلم `nav`: سمِّه بـ `aria-label`. استخدم قائمة روابط لا تبويبات، فلا حاجة لنموذج مفاتيح الأسهم.
- للصفحة الحالية `aria-current="page"` وهي أيضًا غامقة ومسطّرة، فلا تعتمد على اللون.
- للإدخال المركَّز حدّ بسمك 2px: أسود على الرمادي وأبيض على الأساسي. النص 4.5:1 والأيقونات 3:1 في الفاتح والداكن.
- يصل Tab إلى الشريط المتمرر: يظهر كل إدخال حين يأخذ التركيز.
