## Usage

```tsx title="layout.tsx"
import { ZoomInAreaIcon, TextFontIcon } from "@hugeicons/core-free-icons";
import { SecondNav } from "@/components/dga/second-nav";

export function PageInfo() {
  return (
    <SecondNav
      aria-label="Page information"
      items={[
        { kind: "weather", label: "Cloudy 24°" },
        { kind: "date", label: "3-September-2024" },
        { kind: "time", label: "2:30 PM" },
        { kind: "location", label: "Riyadh" },
      ]}
      actions={[
        { label: "Zoom in", icon: ZoomInAreaIcon, iconOnly: true, onClick: () => {} },
        { label: "Text size", icon: TextFontIcon, onClick: () => {} },
      ]}
    />
  );
}
```

Use it for context that belongs to the whole site: the weather, the date, the time and the location, and tools such as zoom. Put it in the `top` slot of a [Header](/docs/components/header). Each entry has a `kind` (`weather`, `date`, `time` or `location`) that brings its icon, or an `icon` of your own; `iconOnly` shows just the icon and keeps the `label` as its accessible name. The strip has two parts, the items at the start edge and the actions at the end, spread apart with no divider between them; it scrolls from the start edge. An optional `links` menu can sit at the start or in the centre (`linksPosition`).

## Anatomy

- **Strip**: 40px high, padded 32px, centred and 1280px wide unless `fullWidth`. **Gray** is neutral-100 with a line under it, **primary** is the brand fill with on-colour text.
- **Item** (`items`, part `SecondNavItem`, DGA: sub-header-Item): an optional icon and text sm Regular, 4px apart, 24px high, centred on the strip. It has a default state and an on-colour state (on the primary strip, or with `tone="on-color"` when used alone). An entry is plain text, a link when it has `href`, or a button when it has `onClick`.
- **Actions** (`actions`): the same item at the end of the strip, icon and text or icon only. The items and the actions are the two parts of the strip; there is no divider between them.
- **Links menu** (`links`, optional, not DGA): a row of links, at the start (`linksPosition="start"`, before the items) or in the centre of the strip (`"center"`).
- **Current entry** (`current`): bold, underlined, `aria-current="page"`. Used by the links menu.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves to the next link or button. Plain text is not focusable. |
| <kbd>Enter</kbd> | Follows a link or presses a button. |

- A `nav` landmark: name it with `aria-label`. Use a list of links, not tabs, so no arrow-key model is needed.
- The current page has `aria-current="page"` and is also bold and underlined, so it does not rely on colour.
- A focused entry has a 2px outline: black on gray, white on primary. Text is 4.5:1 and icons 3:1 in light and dark.
- A strip that scrolls is reached with Tab: each entry scrolls into view when it takes focus.

## Deviations from DGA

- Figma draws fixed switches (Show Item 2, 3 and 4, Show Action 2, 3 and 4). Here `items` and `actions` are arrays.
- Ready-made item `kind`s (weather, date, time, location) and `iconOnly` actions are added, so the icons and the accessible names come with the item.
- The optional `links` menu (at the start or in the centre) and the link, button and current states are added. DGA draws no links here.
- Items are Text sm and 16px icons, smaller than the Text md of the earlier version, and the two parts are spread apart with no vertical divider, as in Figma.
- The strip scrolls instead of wrapping.
