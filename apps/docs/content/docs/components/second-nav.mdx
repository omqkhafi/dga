## Usage

```tsx title="layout.tsx"
import { SecondNav } from "@/components/dga/second-nav";

export function PageInfo() {
  return (
    <SecondNav
      aria-label="Page information"
      items={[
        { label: "Sunday 8 November" },
        { label: "24° Cloudy" },
      ]}
      actions={[
        { label: "Text size", onClick: () => {} },
        { label: "Help", href: "/help" },
      ]}
    />
  );
}
```

Use it for context that belongs to the whole site, or as a row of links to the sibling pages of a section. Put it in the `top` slot of a [Header](/docs/components/header). Pass icons with `icon`.

## Anatomy

- **Strip**: 40px high, padded 32px, centred and 1280px wide unless `fullWidth`. Text md Regular. **Gray** is neutral-100, **primary** is the brand fill with on-colour text.
- **Items** (`items`): an icon and text, 4px apart. An entry is plain text, a link when it has `href`, or a button when it has `onClick`.
- **Divider**: between the items and the actions (`divider`).
- **Actions** (`actions`): at the end of the strip.
- **Current entry** (`current`): bold, underlined, `aria-current="page"`.

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves to the next link or button. Plain text is not focusable. |
| <kbd>Enter</kbd> | Follows a link or presses a button. |

- A `nav` landmark: name it with `aria-label`. Use a list of links, not tabs, so no arrow-key model is needed.
- The current page has `aria-current="page"` and is also bold and underlined, so it does not rely on colour.
- A focused entry has a 2px outline: black on gray, white on primary. Text is 4.5:1 and icons 3:1 in light and dark.
- A strip that scrolls is reached with Tab: each entry scrolls into view when it takes focus.

- Links, buttons and a current state are added, and the strip scrolls instead of wrapping.
