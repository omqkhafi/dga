## Accessibility

- `role="status"` with a visually hidden label, so screen readers announce it once. Translate the label for Arabic pages.
- With `label={null}` the spinner is hidden from screen readers. Use this when the surrounding element already announces the busy state, as [Button](/docs/components/button) does.
- With reduced motion, the spinner turns slowly instead of stopping, so the busy state stays visible.
