## الاستخدام [#usage]

```tsx title="page.tsx"
import { List, ListItem } from "@/components/dga/list";

export function Steps() {
  return (
    <List type="ordered" markers="arabic" aria-label="الخطوات">
      <ListItem>أنشئ حسابًا</ListItem>
      <ListItem>وثّق هويتك</ListItem>
      <ListItem>أرسل النموذج</ListItem>
    </List>
  );
}
```

استخدم القائمة لعناصر قصيرة قليلة مترابطة: خطوات أو متطلبات أو ملاحظات. واستخدم `ordered` حين يهم الترتيب، و`unordered` حين لا يهم، و`icon` حين تعين الأيقونة على المسح البصري. ولصفوف بأعمدة عدة استخدم `StructuredList` أدناه، أو [Table](/docs/components/table) لبيانات تُرتَّب. ولا يعرّف DGA صفوف قوائم بصور شخصية أو أوصاف أو إجراءات؛ فضعها في [Card](/docs/components/card) أو صف في Table.

## البنية [#anatomy]

- **List** (عنصر `ul` أو `ol`): خط Text md، وارتفاع العنصر 24px على الأقل. وقيمة `tone` إما `primary` أو `neutral` (الافتراضي) أو `onColor` للخلفيات بلون العلامة.
- **العلامة**: نقطة 4px، أو `١-` ثم `أ-` في المستوى الأدنى (مع `markers="arabic"`)، أو أيقونة 16px. وتأخذ العلامة لون النص.
- **المستوى الثاني**: ضع `List` داخل `ListItem`؛ فيُزاح 24px.

## إمكانية الوصول [#accessibility]

| المفتاح | الإجراء |
| --- | --- |
| <kbd>Tab</kbd> | يدخل Structured List القابل للاختيار (إلى الصف المختار) ثم يخرج منه. |
| <kbd>ArrowDown</kbd> | يختار الصف التالي. |
| <kbd>ArrowUp</kbd> | يختار الصف السابق. |

- القوائم عناصر `ul` و`ol` حقيقية، والعلامات المرئية مخفية عن قارئات الشاشة فتُقرأ القائمة المرتبة مرة واحدة مع موضع العنصر.
- Structured List جدول HTML. والقابل للاختيار مجموعة أزرار اختيار: تغيّر مفاتيح الأسهم الصف ويُعلَن الصف المختار.
- النص بنسبة 4.5:1 والأيقونات 3:1 في كل لون، فاتحًا وداكنًا، وعلى لون العلامة فوق تعبئاته.
