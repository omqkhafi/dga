title: Contrast

---

The token build fails if any pair below is under WCAG 2.1 AA, in light or dark mode: 4.5:1 for text, 3:1 for icons, borders that carry meaning and focus rings. Disabled states are exempt (WCAG 1.4.3). Each row is the lowest ratio across the surfaces that variant and state can sit on.

Component pages show the same data for one component, collapsed. [Foundation pairs](/docs/deviations#how-contrast-is-checked) (text, icon and status tokens on page surfaces) are checked by the same build.
