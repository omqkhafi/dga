مسافات DGA سلّم بوحدة 4px. وخطوة المسافات في Tailwind هي 4px أيضًا (0.25rem)، فتقابل كل خطوة في DGA أداة رقمية مباشرة: `--spacing-4` (‏16px) هو `p-4`، و`--spacing-80` (‏320px) هو `p-80`.

## اتجاه RTL والخصائص المنطقية [#rtl-and-logical-properties]

استخدم الأدوات المنطقية فقط، ليعمل تخطيط واحد بالعربية والإنجليزية:

| استخدم | لا تستخدم |
| --- | --- |
| `ms-*` و`me-*` | `ml-*` و`mr-*` |
| `ps-*` و`pe-*` | `pl-*` و`pr-*` |
| `start-*` و`end-*` | `left-*` و`right-*` |
| `border-s` و`border-e` | `border-l` و`border-r` |
| `rounded-s-*` و`rounded-e-*` | `rounded-l-*` و`rounded-r-*` |
| `text-start` و`text-end` | `text-left` و`text-right` |

تفشل اختبارات المستودع عند أي أداة أو خاصية CSS فيزيائية لليسار أو اليمين.
