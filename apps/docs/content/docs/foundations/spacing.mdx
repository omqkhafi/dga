DGA spacing is a 4px scale. Tailwind's spacing step is also 4px (0.25rem), so every DGA step maps directly to a numeric utility: `--spacing-4` (16px) is `p-4`, `--spacing-80` (320px) is `p-80`.

## RTL and logical properties

Use logical utilities only, so one layout works in Arabic and English:

| Use | Not |
| --- | --- |
| `ms-*`, `me-*` | `ml-*`, `mr-*` |
| `ps-*`, `pe-*` | `pl-*`, `pr-*` |
| `start-*`, `end-*` | `left-*`, `right-*` |
| `border-s`, `border-e` | `border-l`, `border-r` |
| `rounded-s-*`, `rounded-e-*` | `rounded-l-*`, `rounded-r-*` |
| `text-start`, `text-end` | `text-left`, `text-right` |

The repository's tests fail on any physical left/right utility or CSS property.
