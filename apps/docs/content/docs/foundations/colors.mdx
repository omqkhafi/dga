DGA colours come in two layers. **Primitives** are the raw palettes (SA Flag green, gold, lavender, neutral, status). **Semantic tokens** (`--text-primary`, `--background-body` …) point at primitives and switch between light and dark. Use semantic tokens in components so dark mode works on its own.

## Utilities

Every semantic token has two Tailwind utilities.

| Kind | Rule | Example |
| --- | --- | --- |
| Figma-identical | `{utility}-{token name}`, one-to-one with the Figma variable | `text-text-primary`, `bg-background-body`, `border-border-primary` |
| Short alias | The token name without its category prefix | `text-primary`, `bg-body`, `border-primary` |

Short aliases exist only for `background-*`, `text-*` and `border-*` tokens. An alias is skipped when it would hide a palette colour (`bg-white`, `bg-neutral-50` stay the raw palette) or change a shadcn utility's meaning (`bg-primary`, `bg-secondary` stay shadcn). In those cases use the Figma-identical form.

```tsx title="page.tsx"
<p className="text-primary-paragraph">…</p>      {/* alias */}
<p className="text-text-primary-paragraph">…</p> {/* Figma-identical, same colour */}
```
