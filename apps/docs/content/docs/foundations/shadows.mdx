Values come from the Figma effect styles. On the site CSS, `shadow-sm` uses 6% and 10% opacity; Figma uses 5% for both layers, and DGA UI follows Figma.

Backdrop blurs use `backdrop-blur-sm` (8px), `md` (16px), `lg` (24px) and `xl` (40px).
