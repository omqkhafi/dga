DGA uses **IBM Plex Sans Arabic** for Arabic and Latin text, in four weights. `dga-style` loads it with `next/font` (Arabic and Latin subsets) and exposes it as `font-sans`.

## Scale

<TypeScaleTable />

Body sizes (`text-xl` to `text-2xs`) keep their desktop values on every viewport. Figma's Mobile mode shrinks `text-md` to 12px and `text-xs` to 8px, which is too small to read; see [Deviations](/docs/deviations). Display sizes `md` and larger use -2% letter spacing, as in Figma.

Figma also lists italic styles. IBM Plex Sans Arabic has no italic, so those tokens are not emitted.

## Usage

```tsx title="page.tsx"
<h1 className="text-display-lg font-bold text-display">…</h1>
<p className="text-md text-primary-paragraph">…</p>
<span className="text-sm text-secondary-paragraph">…</span>
```

Each `text-*` size sets its line height too. For Arabic text, raise it as described under [Arabic text](#arabic-text), and never use `leading-none`.

## Responsive modes

The type tokens change at these widths (mobile-first):

| Mode | Applies from |
| --- | --- |
| Mobile | 0px |
| Tablet | 768px (`md`) |
| Desktop | 1024px (`lg`) |

## Arabic text

Arabic needs four settings that Latin text does not. The docs site applies all four on every Arabic page; copy them into your own project.

```css title="globals.css"
:lang(ar) { line-height: 1.8; }
:lang(ar) :where(h1, h2, h3, h4) { line-height: 1.5; }
:lang(ar), :lang(ar) * { letter-spacing: 0; }
```

- **Font.** IBM Plex Sans Arabic for Arabic and Latin, so a line that mixes both keeps one voice.
- **Line height.** 1.8 for body text and 1.35 to 1.5 for headings. The marks above and below Arabic letters need more room than the token line heights (1.4 to 1.6) give, which is why `leading-none` is never used on Arabic text.
- **No letter spacing.** Negative tracking, including the -2% on display sizes, breaks the joins between letters. Set it to 0 in Arabic, and for any `tracking-*` utility.
- **Numerals.** Western digits (0 to 9) in prose and in every technical value (versions, ratios, sizes, counts, dates). Arabic-Indic digits (٠ to ٩) only in sample content that imitates a citizen-facing service, such as the national address card on the home page. Never mix the two systems inside one view. This is a DGA UI convention, not a DGA rule.
