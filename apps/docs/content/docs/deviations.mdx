## How contrast is checked

The token build fails if any of these pairs is below WCAG 2.1 AA, in light or dark mode:

- Text and link colours on `background-white`, `background-body` and `background-card` (4.5:1).
- Icons and link icons on the same surfaces (3:1, non-text).
- `text-oncolor-primary` and `icon-oncolor` on every solid fill (primary, status, nav header, button fills).
- Status text on its own tinted background (`text-success` on `background-success-50`, and so on).

Disabled states are exempt (WCAG 1.4.3). Component-level pairs are checked as each component is added.
